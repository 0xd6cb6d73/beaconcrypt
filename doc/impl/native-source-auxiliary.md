# Native auxiliary callbacks and the shared oracle

The native Phase-1 writer, public-key validator, allocation requests and response writer do not call the CTX hash service. `PqxdhSourceAuxiliary` gives them a concrete local-state interface and lifts that interface over the complete retained commitment cache. The cache is inaccessible to those callbacks by type. Their native codec, allocation and validation behavior remains a functional contract; this result does not assert that an arbitrary shared-state environment has the same behavior.

`lift_step` gives the exact single-call result, auxiliary poststate and unchanged cache. `lift_complete` extends that equation to every adaptive continuation, including failure replies. `lift_uniform` shows that the lifting keeps the entire actual uniform-query bill. These statements concern the evaluated program with full retained state, not only a marginal reply distribution.

`phase1_step` passes the exact signed candidate to its writer. `server_check` returns the native functional public-identity validation result. `server_reservePeer` and `server_reservePlaintext` preserve the actual allocation result and the requested plaintext length. `server_write` passes the full response fields and retains the actual optional output and auxiliary poststate. `server_erase` fixes logical temporary-buffer erasure to a unit return: it provides no callback that can observe the erased secret bytes, and it makes no physical-erasure claim.

`server_complete` identifies the entire adaptive auxiliary program with the local interpreter while retaining every previous hash entry. `phase1_uniform` charges the complete supplied writer bill. `server_uniform` charges the complete peer-allocation, plaintext-allocation and response-writer bills, with public-key parsing and logical erasure making no uniform requests. Deterministic running time is not claimed to be zero, and no opaque ambient randomness is treated as free.

These twelve checked statements provide the concrete auxiliary handlers needed to run the source prefix through the same ordinary shared oracle from its empty initial state. They do not by themselves establish that prefix simulation, initialize a challenger from an arbitrary retained cache, or prove a cryptographic advantage bound. The source compiler must actually install these handlers. Snapshot and persistence behavior are outside this model.
