# Complete two-world source-prefix coupling

This cohort proves a relation between the two complete evaluated prefix distributions at the actual prepared later-record input. It retains the initial Builder, every complete callback result, the source frontend and installation trace, all native private fields, and the actual shared ROM cache. A cut before challenge admission has the same original callback and adversary request/continuation in both worlds; only the explicitly appended outside challenge wrapper differs. Every other outcome remains in the coupling. No prefix is conditioned on reaching the target or on a successful send.

The result is an operational bridge for the existing saved-continuation proofs. It is not a new cryptographic assumption, a primitive reduction, or the final evolving-chain secrecy theorem. In particular, it does not identify the two complete post-challenge distributions. The completed, inside and used outcomes are retained as an explicit pair that still needs the existing source-event exclusions and completed/cached probability bounds in their actual common experiment.

## Source phase facts

`PqxdhLaterChallengeScanPhase.reaches_kept` shows that every actually reached adaptive source prefix preserves an already selected challenge pair and optional reply. `used_pending` applies that fact to the original captured scan: a later pending callback stays in the used phase. `admitted_used` proves that the first equal-length challenge chooses its pair even if its source send returns no record. `admitted_pending` splits the actual complete scan at that request, so a pending outcome is either inside the same admitted callback or after the pair was selected. Its proof uses the complete native callback execution to obtain the actual source result; it does not infer chronology from a marginal key distribution.

`before_handler` proves that an ordinary request or an unequal-length challenge request runs the same whole handler for either bit. `before_unused` proves that each possible reply retains an unused pair, and `before_phase` identifies the exact carried metadata as a before cut. The `Late` predicate retains a complete result or an inside/used pending result with its original native state; it is not a discarded-event flag.

## Coupling the complete scans

`PqxdhLaterChallengeScanCoupling.run_query` factors the actual captured scan at its complete callback boundary. The first computation is the real source callback scan. A completed callback continues from its returned wrapper state, frontend, trace and native backend. A pending callback retains that same state and appends the original outside wrapper for its world's bit.

`admitted_late` classifies every actual outcome after an admitted request. `coupled` then inducts over the entire adaptive adversary program. Before admission, a diagonal coupling shares the real callback scan and recurses on its actual returned state. At admission, the existing product-coupling theorem retains both complete actual distributions, each in its completed/inside/used branch. It changes no marginal distribution and claims no equality between post-admission outcomes. The complete scan programs use `ProbComp`; a failed source send is an ordinary optional result and remains in the program rather than becoming lost probability mass.

`PqxdhLaterChallengeBuilderCoupling.run_builder` factors the original initial Builder followed by the adaptive wrapper. `coupled` shares that Builder's complete native execution, including an unsuccessful Builder reply. A cut inside the Builder keeps its original callback in both worlds and appends each literal wrapper; a completed Builder enters the checked wrapper coupling with the same returned frontend, trace and native state.

`PqxdhLaterChallengePrefixCoupling.shared` instantiates the relation at the existing shared-ROM callback compiler. The `restore attach` map reassembles the local fields and the actual reached ROM cache into the native state: it neither installs a chosen cache nor erases any field. `prepared` supplies the concrete prepared input, its original private callbacks, selected message, first 64-byte expansion, target depth and original shared cache. Both directions of record dispatch and all ordinary requests already represented by this source program are retained. The theorem quantifies over the complete native callback interpreter, so it does not exchange independently sampled keys or reorder the source generators.

## Exact measured before-cut distribution

`PqxdhLaterChallengePrefixMass.beforeKey` observes the full carried request/callback and native state at a before cut. It returns `None` for a Builder cut, a completed run, or a post-admission cut. `late_key` and `related_key` prove that the complete prefix relation gives equal observations. `prepared_before` therefore proves equality of the evaluated distributions of those observations for the two original prepared scans. This equality includes the probability of `None`; it neither renormalizes the before branch nor asserts that the complementary probability is zero. It is derived from the full coupling, not from a support-only implication.
