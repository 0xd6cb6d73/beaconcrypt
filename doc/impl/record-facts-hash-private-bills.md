# Complete source private digest-query bill

`PqxdhRecordFactsHashPrivateBills.source_private` proves that the complete initialized `HashSource.compiler` execution of the actual adaptive `Protocol.program` makes at most `budget.sends` private digest queries. A private query is exactly a combined-oracle request at a `(material label, outer suffix)` address. Ordinary hash addresses and finite coin requests are different query categories. The theorem counts every logical private request, including a repeated address, before the memoizing digest interpreter decides whether the address needs a fresh sample.

The coefficient is one. The existing `HashSealBills.program_seals` bound counts every hidden sealing service attempt before any optional reply, rejection or writer outcome. `query_private` proves that its concrete compiler makes at most one private digest request and that every other constructor contributes zero. `program_private` transports this exact service bill through the complete stateful adaptive continuation. `source_private` applies the result to the actual initialized source program and its existing outer `budget.Respects` condition. No target, honest-key, successful writer, freshness, environment framing or mode restriction is needed for this syntactic query count. The separate source-view equality still requires its stated replay/random hidden-mode restriction.

The zero contribution of ambient work is specific to private digest addresses. `coins_private` keeps arbitrary finite-coin work and proves only that those queries are not private digests. `shared_query_private` and `shared_program_private` keep every ordinary shared-hash query and arbitrary adaptive reply. `native_private` applies that result to the complete native program, including actual HKDF, AEAD and writer callbacks. The allocator's entire seed sampler, the lookup's complete 76-byte output sampler, public hash requests, caller-known sends and receives, bookkeeping and publication are all covered by `nonsealing_private`. None is removed from its own uniform, ordinary hash, native primitive or source instrumentation ledger.

This module closes the global private digest-query cap needed by the subsequent combined-cache collision argument. It does not yet claim a collision probability, a source binding/origin theorem, or the other global query caps. It adds no primitive or protocol-security assumption and changes no Rust, codec, registration or deployment behavior.
