# Publication evidence at the current transcript prefix

`PqxdhRecordFactsOriginPublicationHistory` defines `History` relative to a literal current transcript. Every hidden seal entry must have its actual owning sender and matching frame, with either failure of that frame's writer or a ciphertext already published by that sender in this transcript. This is an operational invariant to be established from source execution, not a new security or primitive assumption.

The six statements explain its preservation. `published_append` retains an earlier publication when a transcript grows. `current_published` puts a ciphertext actually returned by the current entry into the newly extended transcript. `history_transport` retains prior evidence under source control progress and exact dictionary equality. `history_extend` combines those facts with the exact old-or-created dictionary split. `native_history` discharges that split using the reviewed actual native execution, so every native call advances the invariant to its literal appended query/reply entry. `history_publications_eq` allows the secrecy wrapper to re-express an entry when its publication observation is identical.

The source theorem uses only the existing replay/random restriction, control safety and successful-writer `FrameReadBack`, plus the prior `History` induction input. It retains the complete actual execution and introduces no oracle call, probability term or cost waiver. The global initialization, test/fresh secrecy-wrapper joins, arbitrary full continuation and precise unpublished-accept event extraction remain separate work. These six guarded results do not claim that a failed writer published its frame or that final dictionary membership establishes publication before an earlier receive. Rust, registration, persistence and snapshots are unchanged.
