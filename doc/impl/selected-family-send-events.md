# Source seal events across the adaptive family

`RawCtxSourceEventRecorder` and `RawCtxSelectedFamilySendEvents` connect the retained source audit to the complete original Server, Beacon and public record schedule. The audit is private analysis state. It records actual derivation replies and actual pending seals while preserving every original oracle reply, role, cache and private poststate. The result supplies routing evidence for the later nonce analysis; it does not yet bound nonce repetition.

The recorder's `query` and `program` equations equate its ordinary stateful execution with the existing optional source observer. The outer `some` records that this source interpreter has no compiler refusal. Native optional plaintext and ciphertext remain inside that value and are never replaced by a manufactured success. `mem_seals` retains repeated equal occurrences, and `nonseal_query` and `nonseal_program` show that source queries and derivation events cannot add, remove or reorder seal occurrences. `source_queries` counts zero private seal events when forwarding an original source program. This is an instrumentation count, not a claim that the source program performs no cryptographic work.

The family proof first instantiates the recorder with the actual combined native receive, send and public services. `send_lift` and `send_observed` connect its send callback to the previously checked scalar send. `send_history` appends exactly the original derivation/seal trailer, including a writer that returns no frame. `send_preserves` carries the original admission and ready-callback evidence for every retained seal. Neither distinct event values nor an honest owner nor unique chain bytes are premises.

`receive_query_quiet`, `receive_quiet` and `receive_preserves` cover the full cached and future receive program, all derivation replies and all opening outcomes. Receives emit no sealing event and preserve all previously recorded seals. `public_preserves` leaves the complete seal list unchanged while retaining the actual public service's reply and shared-state effects. The family invariant's receive/send callback obligations are proved from these concrete source executions; they are not assumed as a protocol security contract.

`family_preserves` handles every original role operation, with no nonempty-family premise. `schedule_preserves` lifts it through every adaptive continuation and early final return. `observed_routed` establishes the same invariant in the exact observer already connected to the complete native family execution by `RawCtxSelectedFamilySourceAudit.observed_native`. Starting from an empty audit, `selected_chain` proves that every recorded selected seal has an actual normal source admission and ready callback, that its old sending chain is exactly the selected chain input, and that it did not bypass retained-parent priority. Empty audit means the analysis starts at this suffix; it imposes no honesty or emptiness condition on the supplied source roles or primitive state.

The native correspondence uses the existing retained selected-KDF table with real public HKDF calls. It is not yet a comparison against the full production KDF distribution. Owner labels are supplied by the original frontend, but their registration installation origins and chronological path provenance remain separate obligations. In particular, equal occurrences are not asserted to be distinct source positions, and the routing theorem alone does not imply a small collision probability or per-key nonce uniqueness.

The eighteen guarded statements add no primitive security assumption and no reduction advantage. The complete observer has exactly the original native uniform-query allowance by `RawCtxSelectedFamilySourceAudit.observed_uniform`; no original callback is charged zero. The earlier scalar send theorem bounds its event trailer by two entries. This package does not introduce a new whole-family event-count bound or a runtime bound for list bookkeeping. Live reveals, registration installation, the actual component nonce ledger, ancestry/candidate attribution and the final nonce probability must still be connected to the same global experiment. Primitive implementations, snapshots, persistence and restoration remain outside scope.
