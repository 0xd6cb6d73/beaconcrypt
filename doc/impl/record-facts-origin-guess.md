# Unconditional commitment guessing after one bit

`PqxdhRecordFactsOriginGuess` proves four elementary probability statements for the actual uniform 64-byte commitment type. `fixed_guess` bounds one optional fixed guess by `1 / 2^512`. `independent_guess` retains that bound for a complete probabilistic continuation whose input does not include the sampled digest. The proof commutes the two independent computations and applies the exact uniform point mass; it never conditions on a writer outcome.

`bit_guess_split` allows any deterministic Boolean function of the digest to select one of two fixed probabilistic continuations. Its guessing probability is bounded by the sum of the two unconditional fixed-continuation guessing probabilities. `one_bit_guess` consequently gives `2 / 2^512`. The continuation may be adaptive internally, and the guessing function may return no candidate. The type explicitly exposes the allowed dependency: the continuation receives the chosen Boolean, whereas the event alone reads the sampled digest.

These are generic counting lemmas, not a protocol security assumption or a source-level origin bound. A failed-writer source simulation must still prove that its selected commitment influences the simulated continuation only through the permitted bit before the first selected guess. The actual successful publication branch can expose the complete digest-containing ciphertext and must be stopped or excluded for that selected unpublished target; this module does not claim that a literal successful reply leaks only a bit. Actual private-cache freshness, repeated raw attempts, temporal seal/receive selection, identical-until-bad coupling and global query accounting remain separate source obligations. No primitive implementation, parser, freshness or security contract is introduced.
