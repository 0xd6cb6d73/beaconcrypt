# PB-D: classical source join of the whole deployment game

`PqxdhBoundaryDeployment` closes survey rows PB-12 and PB-14 for the classical common deployment experiment. It defines the adaptive source game `sourceGame` and proves eight guarded statements that equate it with the frozen CE game `PqxdhDeploymentSecrecy.game` at the production codec on the full returned value, plus the whole-program join, an index-0 instance, a normal-return statement, and generic continuation, observation and event transfers for item 8. They are exact operational equalities; they add no security game, primitive contract or cryptographic conclusion.

The source game. `sourceGame setup codec reader erased checks ensureInit identityIndex bounds mode A` runs, from a runtime state, the source-ordered Server birth `PqxdhBoundaryBirth.serverBirth setup.joint ensureInit identityIndex setup.serverKeyId` (runtime initialization, then one generated identity seed; a failed initialization returns no outcome with the runtime it returned and draws nothing). The secrecy layer is CE's (classification E): it keeps the transcript, the hidden test bit and the fresh messages, and issues only coins and sends for the test and fresh commands. As in the step module, codec′ is `PqxdhBoundaryRecordPrelude.withReader codec reader` and route′ is `RawCtxFrameDecoding.sender reader.model` (decision D-2, message #511).

Its returned value has type `Outcome KemSK X × A`: on a successful birth, the encoded created Server, the literal Rust result of the adaptive execution (on success the adversary output together with its final ledger, which is where `wrap` returns them) and the complete final deployment state (owners, Server, pending tokens, both caches, raw-attempt counters, produced frames), then the runtime. `okMap` turns a CE game value `(created, output, (ledger, state))` into `(created, ok (output, ledger), state)`, the inverse of the ledger move of `PqxdhDeploymentSecrecy.run_wrap`, and keeps the runtime; `unwrap` reads a source value back and is a left inverse of `okMap` (`unwrap_okMap`), so no part of the game value is lost.

Statements. `execute_exact`: for every native-interface program and complete deployment state, `PqxdhBoundaryProgram.execute (sourceStep …) work state` equals the CE native simulation `simulateQ (PqxdhDeploymentNative.handler setup codec′ checks route′ serverSeed) work` run from that state, with every reply wrapped in `ok` and the complete final state (`PqxdhBoundaryProgram.source_exact` with `step_exact`). `classical`: for every setup, codec, frame reader, buffer, `checks`, `ensureInit`, identity index, fresh bounds, mode, adversary and runtime, `(sourceGame setup codec reader erased checks ensureInit identityIndex bounds mode A).run runtime = okMap <$> (PqxdhDeploymentSecrecy.game setup codec′ checks route′ ensureInit identityIndex bounds mode A).run runtime`, on the full returned value with no projection, conditioning or event premise; the proof uses `PqxdhDeploymentSecrecy.game_wrap`, `PqxdhBoundaryBirth.server_source` and `execute_exact`. `classical_zero` is the identity-index-0 instance used by the CE-12 headline games (PB-D pin #415). `classical_normal`: every supported source outcome is `okMap` of a supported CE game outcome, so the source game never returns a Rust `fail` or `div`. `classical_continuation`: any continuation of the source game sees exactly the CE game's value through `okMap`. `classical_observe`: for every observation `observe` of the CE game's value, `(fun outcome => observe (unwrap outcome)) <$> source = observe <$> game` as computations, which is the form the CE-12 headlines use (`𝒟[decision <$> game] {true}`). `classical_probEvent`: for every event `event`, `Pr[event ∘ unwrap | source] = Pr[event | game]`.
