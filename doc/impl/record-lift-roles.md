It implements the record-state part of R2 without depending on the provisional `PqxdhRecordLiftInterface` candidate boundary. The module adds eleven operational statements and no cryptographic assumption or security bound. It does not implement the generic record-lift world, registration, hidden-slot installation, transient finish candidates, evolving-key hybrids or CTX compilation.

Complete owner values retain their existing inactive fields and outer identifiers so that established and inactive dispatch use the exact source definitions. The separate `ownerRaw` coordinate follows `PqxdhDeploymentNative` exactly; the stored owner's own counter is not substituted for it.

Both use `PqxdhDeploymentNative.logged` and retain the primitive interpreter's entire returned state. `produce` changes the projected log by the same append as the native logger; `putback_produce` proves that reinstalling it is exactly `PqxdhDeploymentNative.produce`. Thus rejected operations retain their actual primitive effects, source rollback and consumption occur inside the unchanged handlers, and writer failures retain their produced frames. Missing Beacon indices return the native absent-owner reply without changing a counter; an existing inactive owner follows the source rejection path, which increments its raw-attempt counter on a raw call.

The primitive interpreter is a parameter of `serverStep`, `beaconStep` and the combined `handler`. All ordinary record calls share the same auxiliary/cache pair.
