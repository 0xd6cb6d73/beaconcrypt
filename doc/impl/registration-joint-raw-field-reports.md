# Actual raw registration reports and the joint signature reduction

This checkpoint connects the previously checked generated/imported identity compiler to the existing ordinary joint-use weak-EUF game. It constructs the reduction from the actual initialized one-Server/many-Beacon registration schedule. Every successful raw `accept` command reports its original public candidate against every reserved generated identity index. A report detects a valid accepted field whose message had not been signed for that generated identity and whose identity had not been revealed at that report. The theorem bounds the probability of any such report by the sum of the explicitly constructed single-identity joint-use advantages. It does not yet state full authenticated-root security or identify every nonforged accepted tuple with an actual source signing attempt.
