# Actual preparation and application callbacks preserve the CTX cache

`PqxdhInitialCtxFreeCallbacks` supplies the concrete cache-independence fact needed before the existing current Beacon compiler can run its preparation and application getters through a shared-ROM prefix interpreter. Its eight checked statements concern the literal existing source callbacks. They do not assume that an arbitrary callback is independent of the cache, and they deliberately exclude raw receive callbacks, whose commitment operations use that cache.

`direct_cache` inspects every non-raw branch of `PqxdhPhase2SourceAux.directAux`. Local operations receive only the original auxiliary state. Generated identity DH receives the original private identity state and retains all resulting history, while it cannot inspect the CTX cache. Initial fixed-HKDF output is deterministic under its existing source contract. All these operations preserve the incoming cache and produce the same optional result and complete local/identity poststate for any incoming cache.

`auxiliary_evaluated` consumes the existing ordinary interpretation equality, including public CCA forwarding and the complete borrowed joint-identity service. `routed_cache` then handles the actual preparation, application and initializer routes. Selected-key decapsulation still uses the existing blocked CCA interface and retains every optional rejection; local decapsulation retains its original complete effects. Logical erasure and root routing retain their original behavior. The auxiliary representation supplies no raw or private hash access to these branches.

`interpreted_cache` transports this result through the actual retained KEM-handle translation and `PqxdhInitialRootFreeCallbacks.interpreted`. Both known and generated identity handles remain present. The old selected-KEM handle translation is used only at its existing one-selected-key interface; this theorem does not extend that encoding to an unrestricted dynamic KEM pool.

The executable `cacheFree` callback is concretely defined by running that same original interpreter at an empty CTX cache, then projecting away only the cache component. `interpreted_local` proves that restoring the actual incoming cache reconstructs the complete original evaluated program. The empty cache is an implementation of a proved cache-independent local computation; it does not replace the source's shared random oracle with a second oracle or independently sample hash answers.

`preparation_source` and `application_source` consume the literal `PqxdhInitialCurrentBeacon` callbacks. They retain the actual CTX cache, complete root-family cache, auxiliary state, private identity state and optional reply. The application getter still returns its actual optional bytes. These are the concrete equations a shared prefix compiler can use before the first raw opening, without an unproved state-independence premise.

`cacheFree_uniform` proves equivalence of the complete uniform-query bound with the original callback at its reached state. All local sampling, decapsulation, joint-service and ambient primitive work stays charged under the existing bounds. The cache transformation itself adds no primitive request; it is not a claim that deterministic native execution has zero runtime. The source/primitive, codec, logical-erasure and joint-use contracts remain those already documented for the imported interpreters.

This package establishes an operational cache boundary. The consuming prefix must still use the original raw receive path and its one shared CTX cache, preserve actual creation and target selection, retain revealed plaintext and secret-key observations with the appropriate freshness conditions, and prove the remaining cryptographic hybrid comparisons. No new primitive security assumption, smallness claim, authentication conclusion, owner uniqueness, snapshot or persistence behavior is introduced.
