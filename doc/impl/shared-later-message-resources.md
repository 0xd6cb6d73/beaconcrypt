# Complete later-record prefix query accounting

This package supplies resource bounds for the literal later-record prefix already related to the source by `PqxdhLaterSharedMessagePrefix.source` and `adaptive_endpoint`. The bound includes the complete original preparation, the shared 64-byte initializer, all work before a missing parent address, the full continuation when that address is already cached, and the parent76/nonce12/next-chain32 material draws. Completed and rejected branches retain their original decisions. These statements count oracle calls; they do not assert primitive running-time bounds or a completed protocol security reduction.

`RawCtxSharedPrefixCompletion.scan_finish` proves equality of oracle programs after resuming the exact saved request and its complete continuation. It quantifies over the full local state and the annotation coverage and soundness facts. `prefix_bound` then drops a suffix from a syntactic query bound. This argument counts requests answered from a cache and does not infer resource bounds from equality of output distributions.

`PqxdhSharedParentResources.carried_finish` instantiates that equality with the actual native source program and its checked annotations. `collect_finish` covers all three parent outcomes: completed branches keep their decision, cached branches execute the original continuation, and only missing branches need resumption. `prepared_finish` joins the scanner and this collector to recover the full original source program and its final publication/freshness decision. `prepared_bound` consumes the original native callback and post-schedule bounds. It allows seven builder callbacks and at most 67 callbacks per adaptive post request. The cached branch remains within this complete-source allowance.

`PqxdhPreparedSharedParentBounds.bills` supplies the actual preparation, application, selector, auxiliary, and retained initializer callbacks. The initializer pays its existing 32-byte draw. `PqxdhLaterSharedMessageResources.after` constructs the callback certificate from `PqxdhInitialPreparedSourceCaps.callbacks`, using the original sampled KEM secret and challenge ciphertext. Its post bound applies to the actual selection retained in the source packet. The auxiliary disclosure-count field is instantiated with the actual length and proved by reflexivity; that length does not enter this resource result. No budget for an opaque final observer is assumed.

Write `H0 = 69*qMain + 1 + 69*qPost` and let `U0` be `PqxdhSourceSharedPreparationResources.uniformCost`, the complete preparation bill explained in [the preparation resource guide](source-shared-preparation-resources.md). Both caps include every source callback and every original adaptive request, including failure paths. For the supplied authenticated-source resource certificate `c`, write `C = max c.qLocal 64 + c.qDecap`, `D = 34 + c.qBase + c.qDecap`, and `A = c.qAux`. These quantities include interpreted local work, base work, and permitted decapsulation costs; they are not zero-cost ambient operations.

`PqxdhLaterSharedMessageResources.later` establishes the following upper bounds for every scan depth:

- Shared hash calls: `H = H0 + 7 + 67*qPost`.
- Local uniform calls: `U = U0 + 184 + (7 + 67*qPost)*(76 + C + C + 32 + D + A)`.

The 184 calls are exactly the four explicit draws of 64, 76, 12, and 32 bytes in the prefix. The multiplicative term is the conservative callback allowance for the full parent preparation; it includes cached continuations, local callbacks, and retained initializer work. The original 76-byte response still supplies its correlated projections. The theorem does not turn repeated projections or public HKDF calls into independent random samples.

`forwarded` gives the same `H` and `U` bounds at the selected-key component interface, together with zero selected seal calls and zero selected raw-opening calls before the cut. Known-key source seal/open computations can occur during that prefix and remain real local computations; their commitment hashes are counted. `evaluated` gives the ordinary shared-ROM interpreter the total uniform cap `U + 64*H`, for every initial cache. A cache hit still counts as a hash request but needs no digest draw; charging 64 bytes for each possible miss is an upper bound. The separately sampled selected message key costs another 32 calls and is explicitly outside these prefix bills.

The four modules contain eleven guarded theorems, all using only Lean's standard logical axioms. There is no new cryptographic assumption, statistical loss, selected-key honesty premise, or primitive implementation proof. This closes the resource obligation identified in [the later-message source guide](shared-later-message-prefix.md). Realizing the subsequent native key-taking observer with the secret-free adaptive CTX interface, connecting the complete global experiment to symbolic events, and deriving all final reduction and selection losses remain separate obligations. Snapshots and persistence remain outside the proof scope.
