# Replay and random endpoint private-cache observation

`PqxdhRecordFactsPrivateCacheRandom.mode_observation` extends the [replay observation law](record-facts-private-cache.md) to both supported per-key ideal endpoints: replay acceptance with ordinary ciphertext sealing, and replay acceptance with random ciphertext sealing. Its explicit `mode ≠ .real` premise excludes the actual AEAD-opening endpoint, whose raw reply is different. This mode restriction is a definition of the compared experiment, not a primitive security assumption.

The `linked` definition compiles the existing `PqxdhRecordLiftIdeal.keyImpl` through the existing shared hash interpreter. `linked_replay` identifies replay mode with the earlier replay handler. In random mode, a seal refuses repeated nonces; otherwise it draws a body of the exact plaintext length, then a 16-byte tag, then queries the actual private suffix cache for the commitment, and finally records the full successful seal. `randomSealing_exact` equates the helper program with this existing endpoint, including the complete resulting state and the sampling order. It assumes no AEAD behavior for these sampled ciphertexts.

`draw_commutes` states that a probability-program draw which leaves state unchanged commutes with private cache completion. `randomSeal_commutes` combines this fact with the existing history and lazy-query commutation lemmas. `random_nonraw_commutes` adds the existing coin and public hash paths. `mode_factor` and `mode_commutes` assemble the replay and random handlers, including the exact same parsed/raw rejection, replay plaintext, `rawAttempts` and private-input instrumentation as the earlier module. They introduce no per-step error term. `mode_observation` applies the checked discard theorem to the full adaptive continuation from any initial state.

The observed result includes the entire continuation result, local nonce/seal/public/private histories, raw-attempt count and shared public ROM. Only the private suffix dictionary is omitted. The law retains the correlation with later seals that query a previously discarded point; it does not independently resample repeated digests or change public hash evaluation.

As in the replay theorem, actual internal uniform-query counts can decrease when discarded draws are removed. This is not a source-cost equality and does not reduce any source or reduction allowance. Original source counts must still be charged. This module proves no global record event, no guessing/collision probability and no cryptographic advantage bound; global coordinate/state transport remains a separate obligation. No new primitive/codec contract, source change, snapshot or persistence model is introduced.
