# Complete later-record callback resource ledger

This package supplies the remaining source-local uniform-call allowance for the executable client from `PqxdhLaterExecutableCompletion`. It preserves the previously checked original sampler, shared cache, saved record/finish/builder and complete adaptive Post. It adds no protocol execution, security assumption or loss.

`PqxdhLaterSavedUniformBounds.state_cost` composes a concrete per-service allowance through the complete stateful source program on every possible oracle-reply path. `owner_step` and `owner_cost` apply that fact to the actual attempted Beacon owner: its complete preparation, initializer, application getter and optional first opening use at most sixteen services. `post_step` covers real record/public/reveal work, source selectors and these complete owners. `post_cost` transports that bound through the existing instrumented Post and charges the request that causes outer refusal before the continuation stops. It uses syntactic oracle-program erasure, not equality of evaluated distributions to infer query counts.

`publication_cost` retains both actual auxiliary publication callbacks, including optional writer failure. `prepare_cost` covers all three saved forms, and `complete_cost` combines the saved request with its original all-reply Post allowance. With a positive uniform service allowance `W` and original Post cap `p`, the conservative continuation bound is `T = 1 + 2W + 16Wp`. The single saved record/finish allowance and two publication allowances are charged even on branches that use fewer calls. These upper bounds do not change those branches' original Boolean decisions or optional results.

`PqxdhLaterExecutableResources.external_uniform` discharges the service allowance with the actual authenticated source certificate. Let `C = max(qLocal, 64) + qDecap`, `D = 34 + qBase + qDecap` and `A = qAux`, using the maintained `callbackCap` and `selectorCap` definitions. The shared allowance is `W = 1 + C + C + 32 + D + A`. The two `C` entries cover preparation and the application class; `32` is the retained root initializer cap; `D` and `A` preserve selector and publication work. No assumed whole-observer allowance replaces these callbacks. `suffix_uniform` supplies `T` for the actual sampled private callback carrier; `client_uniform` combines it with the complete prefix through exact proof-attachment erasure.

`PqxdhLaterExecutableSourceBills.source_bills` consumes the maintained `PqxdhLaterSharedMessageResources.later` theorem directly. Its hypotheses are the original source-interface bounds for local callbacks, base/KEM interpretation, generation, encapsulation, optional allocation/serialization, the source main program and Post. With that theorem's complete prefix bill `U0`, the actual client's four bounds are:

- Uniform-route calls: `U0 + 184 + (7 + 67qPost)(76 + C + C + 32 + D + A) + T`.
- Hash-route calls: `69qMain + 1 + 69qPost + 7 + 67qPost + 1 + p`.
- Selected sealing attempts: `1 + p`.
- Selected raw-opening attempts: `1 + p`.

Here `U0` is exactly `PqxdhSourceSharedPreparationResources.uniformCost` with every named original interface cap supplied to the theorem, and `p` is the source certificate's `postCap`. The separately supplied original `qPost` is the bound used by the complete prefix theorem; no implicit equality with `p` is assumed. The 184 bytes are the original 64-byte initializer, 76-byte parent output, 12-byte nonce and 32-byte next-chain draw. Cached continuations remain inside the prefix bill. The ordinary component game samples its separate 32-byte selected key; that challenger draw is not counted as an executable client's request.

These are explicit interface resource bounds, not native runtime or arbitrary byte-length bounds. The source-local random-call bounds already include their stated base/KEM interpretation, and deterministic HKDF, parsing, lookup, writer and primitive computation remains real. The component's own per-hash randomness, validation/forgery overhead and random ciphertext-byte costs belong to its existing primitive endpoints and are not declared free by this client ledger. Original Gate/Fresh/event attribution, parent-address aliases, the actual nonce-refusal probability and the final primitive-security comparison remain separate joins. The package neither changes reveal permissions nor introduces a fresh, honest, accepted or collision-free execution premise.
