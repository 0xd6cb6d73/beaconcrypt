# Actual successful raw-receive witnesses

`PqxdhRecordFactsOriginAccepted` adds four structural statements for the actual owner receive interface. It preserves the optional plaintext returned by the source service and classifies the selected stored kernel without assuming that selection is hidden or honest.

`ownerReceive_accepted` covers the complete source owner receive, including empty input, parser failure, validation failure and the active receive path. A successful result on a caller-known kernel retains the existing `KnownAt` classification. A successful result on an installed hidden kernel gives an entry in the actual resulting ideal seal dictionary, at that receiver's installed slot and opposite physical direction. The exact raw bytes decode to a frame matching that entry, and the entry's plaintext equals the plaintext actually returned by the source. The recursive cached/future receive, source material attribution and retained-dictionary facts come from the reviewed `OriginReceive` module. No recovered secret plaintext is placed into an adversary-supplied target.

`ownerRun_accepted` preserves the same witness through the literal tagged publication callback. The proof takes the actual callback result and keeps the full executed poststate; only dictionary preservation is needed for this particular predicate. The current source control safety and actual handle-to-kernel lookup remain local induction inputs. The all-label ideal-mode condition explicitly restricts the replay dictionary argument to replay and random worlds. No codec readback premise is needed for receiving: the theorem uses the actual supplied decoder result.

`known_no_slot` shows that a caller-known handle has no hidden installation slot in the ideal view. Combined later with the existing persistence of caller-known kernels, it will exclude a prior caller-known classification when the final target handle is hidden. `matches_unique` shows that two decoded frames matching one actual dictionary entry have equal sequence, sender and complete payload. This is equality of the concrete fields, not an injectivity claim about a cryptographic primitive or arbitrary raw wire encodings.

These support facts add no primitive or deployment contract, oracle call, reduction loss or query bound. All four declarations have exact standard-axiom guards. The dispatcher and adaptive secrecy-ledger induction, final `UnproducedAccept` event elimination, and unpublished-record probability bound remain separate work. This module does not close `OriginStatement`.
