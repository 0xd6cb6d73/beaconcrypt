# The publication observer stops before opening

`PqxdhServerAuthPublicationCutoff` defines the concrete next stage of the withheld-output observer. `beforeRaw` follows an annotated adaptive client until its first selected raw-opening request. It returns those exact bytes as its sole candidate without forwarding, parsing or looking them up. Malformed bytes therefore stop the observer too. A client that terminates before such a request returns no candidate. The seven elementary execution equations state every branch, including the unchanged forwarding of uniform, public-hash and dynamically known-key requests.

Each selected seal is forwarded once with its exact input, and its actual optional CTX record is appended to a private journal before the source continuation receives the reply. This retains cryptographic production even if a subsequent frame writer fails. Begin/completion annotations enter the same journal in execution order and return only `Unit` to the original client. The original continuation never receives the journal. Known-key calls preserve their actual local work, shared hashing and optional replies, including byte-equal aliases of selected keys.

`beforeRaw_zero_raw` proves zero selected opening requests for every annotated client, without a successful-parse assumption or a caller-supplied raw bound. `beforeRaw_budget` preserves an arbitrary generalized query budget of the annotation-erased client; its predicate-class and weighted-plaintext specializations therefore retain the existing hash, coin, seal and selected-plaintext bills. This is an exact oracle-accounting result, not a runtime bound on local journaling or source codec work.

The nonstopping `journalImpl` is an auxiliary observer of the same execution. `journal_erase` removes only its journal and recovers the full annotation-erased component program. `beforeRaw_prefix` executes a prefix with zero selected raw calls completely before continuing the cutoff. `builder_prefix` discharges that premise for the literal annotated registration builder using its existing unconditional zero-raw compiler theorem. It covers arbitrary supplied pending registration and complete Server state, all admission failures, explicit component refusal and native optional failures. `journal_builder` preserves the exact begin, actual component execution and completed local trailer, including its optional outcomes. These equations associate annotations by execution order; they do not reconstruct a record from writer bytes or assert that coordinates are unique.

These fifteen theorems do not yet bound the probability of guessing an unreturned record. The whole protocol handler still needs the observed builder replacement and the receipt classification for the same selected-seal occurrence. The forced-`None` continuation must erase all tag-dependent private records while retaining the actual public state, known-key work and cache effects. Uniformity cannot be conditioned on writer failure. The new publication event also needs its own R1 partition and five KDF comparisons; the completed R1 authentication theorem does not already assert successful outer publication. No primitive contract or maintained symbolic query is changed here.
