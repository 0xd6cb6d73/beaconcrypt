# Base source services in the combined digest experiment

`PqxdhRecordFactsHashBase` proves five complete source equalities for public hash, finite coin, effect charge, publication and seed allocation. Each compiled service returns the exact original erased endpoint result and full private state together with the canonical combined private/shared digest cache. The theorems hold from arbitrary input states and for arbitrary mode assignments in the separate hidden-key family.

`hash_exact` uses the reviewed ordinary shared-hash compiler at the exact requested bytes; existing cache values are reused and a missing value is sampled by the same lazy oracle. `coin_exact` forwards the literal finite-coin request and keeps the whole state. `charge_exact` increments the original effect category and retains every other counter and state field. These bookkeeping operations supply no adversarial capability or primitive assumption.

`publish_exact` publishes precisely the submitted writer buffer under its actual tag and clears that buffer, preserving both commitment caches. It does not equate a submitted frame with a successfully returned message. `allocate_exact` lifts the actual lazy directional-seed allocator, including its cached values and logical lookup/draw counts, into the same finite-coin interface. The complete evaluated sampler distribution and full seed-state poststate are retained; neither half is replaced or resampled independently of the original allocator.

This module does not supply the numerical uniform-query bounds or the global hash budget. Seed and digest sampling, actual source instrumentation and reduction query costs remain explicit obligations in the accounting join. No ambient operation is declared free. The original source and the projected erased interpreter are related by the separately reviewed observation theorem; this module concerns the latter's exact source state. No codec, cryptographic, deployment, freshness or protocol-security premise is added. All five declarations have exact guarded axiom checks allowing only `propext`, `Classical.choice` and `Quot.sound`.
