# Exact cut before an attempted source seal

`PqxdhRecordFactsOriginOrdinalCut` stops the actual stateful probabilistic source program just before its chosen sealing callback is answered. Its cut contains the complete private prefix state, attempted-label history, literal pending seal and exact adaptive continuation. All earlier callbacks execute with the supplied original service. The ordinal counts sealing callbacks before their replies, so failed writers and every rejection after entering that callback count. Outer sends refused before reaching a sealing callback do not count.

`scan_target`, `scan_prior` and `scan_other` describe the literal scanner branches. `scan_resume` proves equality of the full probabilistic programs after resuming the selected callback and saved continuation, including the case where the source finishes before that ordinal. This retains every original reply, private field, shared cache, writer outcome and final result; it is stronger than a marginal-key equality. `scan_reachable` and `scan_prefix` show every supported cut is an actual source Reach prefix with exactly the selected relative ordinal. `selected_index_lt` derives a strict ordinal bound from the existing complete syntactic sealing allowance, which the source supplies as `budget.sends`.

No selected writer result is sampled or used to choose the cut. This module does not condition on writer failure, assume target honesty or introduce a primitive contract. It also does not yet give a global probability bound: averaging the selected continuation and relating all ordinals to a common traced source execution are separate steps. Source and reduction query costs remain those of the full actual services; all earlier work and the resumed suffix execute literally. No Rust, codec, snapshot or persistence behavior is changed.
