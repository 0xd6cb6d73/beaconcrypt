# Selected source reads for seed and full76 masks

`PqxdhRecordLiftMaskedReads` proves 32 deterministic local facts about the source interpretations used by the growing record table. It compares two realizations of an existing `ProjectionCut.Mask` or `SeedCut.Mask` while varying one selected32 value. It preserves the other 44 bytes of a full76 reply, the opposite 32-byte seed half, every other stored entry and all counters. These are structural coordinate equations; equal byte strings at different coordinates do not identify the coordinates, and no injectivity, freshness, cryptographic correctness or security premise is used.

`key_parts` and `chain_parts` unpack the actual split/restore equivalences. A key-part replacement keeps next32 and nonce12, while a chain-part replacement keeps key32 and nonce12. `realize_reads` retains the complete lazy-table counter pair and gives the exact cache lookup: the selected coordinate contains the reconstructed full76 value and every other coordinate has its old value. The mask's retained `before` table can itself contain arbitrary values, including an older selected entry; none of these local read equations assumes a fresh miss.

`Reads coordinate selected` is the exact unconditional source selector: the input is noninitial and its `previous` coordinate equals the selected coordinate. `chain_read`, `chain_next_read` and `chain_key_read` expand the actual chain interpretation with this selector. A next32 replacement supplies the selected input only where the source reads that predecessor. A key32 replacement supplies the retained next32 there; `chain_key_invariant` consequently equates every chain input across two selected key values. `reads_iff_successor` and `chain_successor_read` reduce the selector to the unique structural successor when both positions satisfy their existing directional lower bounds. Those lower bounds matter: the total interpretation uses truncated natural-number subtraction, so a false-direction position zero outside the source domain can read its own position-zero predecessor. The unconditional theorem keeps that case exact instead of assuming it away.

`material_read`, `material_chain_read` and `material_key_read` describe the actual material lookup. A chain-part replacement changes no material read. A key-part replacement changes only the material at the selected structural coordinate, using the supplied key32 and retained nonce12. `material_nonce` proves equality of every source nonce under either replacement. Missing entries keep the existing material interpretation's fallback; the theorems do not invent a new value or a presence assumption.

`receive_request_read` and `send_request_read` apply the selector to the literal `.request` of the erased pending source KDF call, including the original ratchet KDF information string through `nativeRequest`. `opening_key_read` and `opening_chain_read` apply the exact material equation through the cached/future source opening getter. The complete `RustM` result and its optional material shape are retained; no successful lookup is assumed. `opening_nonce` also compares the resulting optional nonce, including a getter failure. `seal_key_read` and `seal_chain_read` use the sealing continuation's original material label. Sequence and context remain the original source values; these equations do not replace them with a predicted successful response.

`seed_parts` fixes the orientation of the actual two-half seed: false selects next32, the initial server-to-beacon chain at position one; true selects right32, the initial beacon-to-server chain at position zero. `seed_realize_replace` compares the complete World states returned by two `SeedCut.realize` calls. Only the selected seed-cache entry is overwritten; the seed lookup/draw counters, actual uniform counter, native and environment counters, primitive cache, owners, used markers and all other World fields are identical. This compares two realizations with the same existing lookup/draw increment and 64 actual uniform calls; it does not remove those costs. The separately returned role kernel is allowed to change with the seed.

`seed_read` uses the actual `SeedCut.seedAt` lookup, including its unchanged fallback at other slots. `seed_chain_read` shows that only an initial chain at the selected slot can read the reconstructed seed; its selected direction reads the supplied32 and the opposite direction reads the retained32. Later chain inputs read the same fixed full76 table. `seed_receive_request` and `seed_send_request` carry this equation to the actual pending native KDF request. They make no claim that changing an initial seed while fixing an arbitrary descendant table preserves a real-HKDF consistency invariant.

`receive_open_reads` proves equality of the complete `NativeAdapters.receiveOpen` computations whenever the actual source sequence getter, material getter and context agree. It obtains equality of the native adapter's chosen total getter results from their exact source equations, then compares the entire optional opening program. `receive_open_chain_invariant` and `receive_open_seeds` instantiate this fact for a replaced cached next32 and for arbitrary seed families at a fixed material table. `send_seal_reads`, `send_seal_chain_invariant` and `send_seal_seeds` give the corresponding whole `NativeAdapters.sendSeal` equality. These are equalities of complete state computations, so the actual optional plaintext, optional writer output and every primitive effect are retained, including attempted frame work when the writer returns `None`. They do not assert equality of the private pending rollback kernels or of subsequent ratchet publication.

This module supplies source read equations for an opaque selected-challenge callback. It does not construct the evolving masked simulator, prove a global reachable-state or label-provenance invariant, identify raw table entries by byte equality, replace real HKDF by a uniform table, establish the whole observer's independence from selected32, or prove a record-layer security bound.
