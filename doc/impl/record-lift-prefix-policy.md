# First-parent prefix policy equality

`PqxdhRecordLiftPrefixPolicy` proves that changing the selector at a dependent child coordinate leaves the entire evaluated first-parent prefix unchanged. The parent and child have the literal `MaskedReads.Reads child parent` relation, and the two selectors agree everywhere except possibly at that child. The result retains the complete private state, counters, random-oracle cache, pending and produced writer logs, original optional replies, and the exact suspended source continuation. It also covers prefixes that complete without reaching the selected parent.

The key source fact is operational. Before the first parent lookup, the scanner never queries the parent and the actual interpreter preserves its missing table entry. Every lookup that the source reaches has an available input. A lookup for the dependent child would therefore require a stored parent, contradicting the same execution's missing-parent certificate. The proof does not assume all-reply syntactic availability: it follows the original interpreter's actual supported replies, retaining the source safety certificate at each step.

`query_agrees` proves complete query equality when the coordinate selector agrees at that request; every other private service is definitionally unchanged. `supported_prefix` composes this through an adaptive private-service client from an explicit operational safety certificate, a missing parent and a scanner-avoidance fact. The initialized `scan_schedule` and `scan_program` endpoints discharge those operational premises using the already proved source certificates. They do not take a caller-supplied reachability, table-validity, independence or security assumption.

The sampled-prefix endpoints `sampled_schedule` and `sampled_program` compare the existing proof-attached samplers themselves. Forgetting the proof is injective on their common result subtype, so the complete original prefix equality transports without drawing a replacement state, filtering outcomes or changing a continuation. The schedule endpoint accepts an arbitrary WorldSpec client; the frozen-program endpoint retains the full environment result and test/fresh ledger in either source mode.

This component adds no random draw or query cost: the two prefix computations are exactly equal, including instrumentation. It does not identify the post-cut suffix policies, prove the initial-allocation analogue, bound aliases or refusals, or establish a cryptographic chain/CTX lift. Its private-state equalities are internal simulation results, not permission to expose hidden state as a security observation. The deferred-child suffix law and the separate initial-allocation proof remain distinct joins.
