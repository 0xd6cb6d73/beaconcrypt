# Complete compiler finite-query accounting

`PqxdhRecordFactsHashFiniteBills.source_decision_total` proves the complete finite-query cap `U + qBody + 16*S + 64*(S+H) + D` for the actual concrete source compiler followed by the memoizing digest interpreter and a permitted randomized decision. Here `U` is the existing `CtxBills.programBill .uniform`, `S = budget.sends`, `H = Ideal.sharedHashTotal`, and `D` is the decision's explicit finite-query bound. Each byte of the existing vector sampler counts as a finite query. Every private or ordinary logical digest request is charged for up to 64 digest bytes; cache hits reuse the old digest and can cost less.

The plaintext term remains explicit. `randomBodyCost` is the length of the actual substituted plaintext at each random-mode hidden sealing request, and zero at other requests. `qBody` bounds that weighted cost over the complete source program and all typed continuations. It conservatively includes requested bytes even if a later width gate rejects. Existing command-count budgets do not bound arbitrary public plaintext lengths, so the theorem takes this resource bill separately and does not derive it from `S`. This is an explicit input-size accounting condition, not a primitive, independence or security assumption. No new finite sampler replaces the source's byte-by-byte sampler.

The native accounting is concrete. `counted_coins`, `counted_program_coins` and `logged_coins` keep the actual functional HKDF, AEAD and optional writer callbacks, every native charge and the complete frame log while proving that those callbacks introduce no explicit finite query. Their ordinary hash requests remain present. `shared_coins` forwards exactly the shared interface's finite requests, and `native_coins` transports the zero explicit finite-query count to the combined compiler. These results do not assign zero runtime or primitive-call cost to native work.

`coins_bound` preserves an entire finite sampler's query bound. `allocate_coins` retains the full directional-seed pair and its lazy table, with at most 64 byte draws on a miss and none on a hit. Lookup uses the checked complete 76-byte expansion cap. `seal_coins` charges the full random body followed by sixteen tag bytes, and zero explicit coins in replay mode. `hidden_coins` retains this bound through selected-key state reinstallation, width rejection and every writer outcome. It keeps the private digest request separate from those explicit coins.

`query_coins` checks all ten source constructors against `coinCost`: the existing uniform category, actual requested random-body bytes and a conservative sixteen tag bytes for each hidden seal. The tag allowance includes nonrandom seals, although their actual explicit finite cost is zero. `weighted_scale` preserves full residual weighted budgets; `program_coins` transports the per-service costs through arbitrary adaptive state; `source_coins` combines the existing framed environment uniform bill, outer command budget, explicit body-byte bill and global hidden-seal count.

`plain_query_total` separately accounts for actual lazy digest interpretation. `interpreted_total` joins the private, ordinary and finite scalar caps of the identical adaptive client; it does not combine unrelated distributions. `source_interpreted_total` applies all three derived source caps. `source_decision_total` then charges the final permitted-view decision's own `D` queries. The `decisionCost` field alone is not treated as proof of a decision bound: the final theorem requires the actual per-view decision query bound.

These are resource theorems for the explicit compiler and its digest interpreter. Equality with the original permitted source view still uses the separate replay/random observation theorem. Original counted source executions may perform additional private-cache completions and uniform instrumentation, whose costs remain in their original source/reduction ledgers. No equality with that larger original cost is claimed. No primitive implementation, Rust, registration, snapshot or persistence behavior changes, and no statistical binding or origin event follows merely from these bounds.
