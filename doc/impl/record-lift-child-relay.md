# Persistent child responses under the full adaptive continuation

`PqxdhRecordLiftChildRelay` factors the actual global masked interpreter through a single persistent child response. The selected parent already retains its public message key and nonce while omitting only its next-chain secret. A child response is requested exactly when a real, unselected lookup structurally reads that parent. Other requests forward their actual uniform operations and preserve the entire source service computation. In particular, public HKDF evaluations, known-key operations, parser outcomes, optional plaintexts, writer failures, allocation caches, shared ROM state, instrumentation and pending or produced frame logs remain present.

`unused_source` proves that a service outside that exact read condition ignores the supplied child through its complete native and private result. `coin_source` proves that all forwarded uniform requests preserve the additional optional child cell. `query_source` and `schedule_source` recover the original fixed-child source service and complete adaptive execution after erasing only that extra cell. The original private state is not projected or discarded in these equalities.

`deferred_source` then applies the existing persistent-cell deferred-sampling law to the entire compiled continuation. Drawing the child at its first actual use has the same law as drawing it before that continuation and supplying it to the original masked source interpreter. The law quantifies over every subsequent probabilistic observation of the complete result and private poststate. It includes executions that never read the selected parent and repeated reads that reuse the same child. It is an evaluated full-continuation law, rather than equality of a marginal output distribution.

All five statements are operational equalities or contextual distribution laws. They introduce no cryptographic contract, source reachability assumption, byte inequality, or oracle-security premise. The draw is an explicit probabilistic program. The original source interpreter's counters remain exact; the separate draw is not silently added to that interpreter's uniform ledger. Its cost must be counted by the enclosing reduction.

This module does not yet identify the independent child with the next concrete mixed-policy hybrid. That identification additionally needs the actual source-prefix closure and child absence, a persistent cache relation through all services, and explicit accounting for the changed draw schedule. It does not establish a final evolving-chain secrecy or CTX security theorem. Its five theorem statements have exact axiom guards allowing only the standard logical axioms. Independent semantic review and publication checks are recorded separately when this stage is integrated.
