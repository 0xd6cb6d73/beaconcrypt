# Exact lazy-oracle collision instrumentation

`PqxdhRecordFactsCollisionOracle` supplies eight checked statements connecting an actual memoizing uniform oracle to the separate two-class fresh-draw collision experiment. Its oracle accepts an arbitrary typed input and arbitrary finite coin queries. A fixed classifier determines whether each input is a target commitment or an ordinary hash input before the answer is sampled. The module is an information-theoretic tool; the protocol-specific compiler and event inclusion remain separate obligations.

`query_project` and `program_project` prove exact equality after forgetting the ghost collision history. The full actual reply and cache remain, including every adaptive continuation. Cache hits return the existing value and make no fresh draw. Cache misses sample once, insert the answer at the original input, and record that very answer in the appropriate history list. Intervening finite coin requests are forwarded with their literal replies.

`query_compile`, `interpreter_compile`, and `program_compile` identify the instrumented lazy oracle with an explicit compiler to `PqxdhRecordFactsCollision.DrawSpec`. The last equality retains the complete client result, real cache and ghost history, merely reassociating their product. It neither substitutes marginal distributions nor assumes that two random-oracle calls with the same input return independent answers.

`draw_budget_mono` proves that increasing either digest-class cap preserves the all-reply bound. `compiler_bound` then derives the constructed draw client's two caps from bounds on the source lazy-oracle requests, including every possible adaptive reply. A cache hit reduces the actual number of digest draws; it cannot invalidate either bound. Finite coin queries are forwarded and do not create a digest-collision opportunity. Their computational query costs are separate and are not asserted to be zero.

`collision_bound` applies the previously proved asymmetric collision potential to this exact compiler. Starting from empty caches and empty ghost history, at most S target requests and H ordinary requests give a collision-flag probability at most S(S+H)/card(Digest). Only equalities involving a target draw set the flag; ordinary-to-ordinary collisions are not charged. The statement is about this explicitly defined lazy-oracle execution, with a syntactic request budget. It does not assume a primitive security game or the desired record-layer binding conclusion.

All eight declarations have exact axiom guards allowing only propext, Classical.choice and Quot.sound. The remaining consuming proofs must connect distinct source commitment labels and actual shared hash addresses to this input type, prove cache-collision event containment, compile the erased source services with every native operation retained, and supply the original source and constructed reduction budgets. No global BindingStatement, selection factor, codec contract, primitive implementation result, or production HKDF replacement is claimed here.
