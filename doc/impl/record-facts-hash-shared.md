# Shared native hashes in the combined digest experiment

`PqxdhRecordFactsHashShared` proves five guarded statements connecting the actual shared commitment-hash interface to the combined private/ordinary digest cache. The compiler forwards ordinary inputs at their exact bytes, retains the original unit tag in the source shared cache, and forwards each finite coin literally. It updates a source cache copy to keep the complete source state coherent with the combined oracle state. The private suffix half remains untouched by these operations.

`query_exact` checks both cache hits and misses against the actual `hashImpl` endpoint. It returns the full source result and state together with their canonical combined cache; a cache hit reuses the existing digest, and a miss samples the original whole 64-byte digest. `program_exact` extends that equality through any adaptive shared-hash continuation. `source_program` shows that the framing around the original shared oracle preserves every unrelated private field.

`nativeProgram_exact` consumes the reviewed native compiler and actual frame logger. It compiles an arbitrary complete native record program into the combined digest interface and returns exactly the original native result, native/effect counters, existing uniform-counter value, shared-cache poststate and literal submitted-frame log. Failed publication and actual optional writer/opening responses remain intact. This is the interpreter whose original uniform-draw instrumentation was separately projected away; the theorem makes no equality claim about that omitted source cost.

`compile_queries` permits at most one explicit hash or finite-coin request for each input shared-interface query. It does not charge a sampled digest as one byte, erase native calls, or supply a global request cap. Digest sampling costs, the original source instrumentation bill, and reduction query accounting remain separate obligations. The later full service compiler must instantiate the ordinary hash, caller-known send/receive and remaining source branches before applying the combined statistical game.

No codec, primitive, secrecy, freshness or deployment contract is added. All source HKDF and AEAD operations remain the original functional contracts exposed by the native compiler. The five statements are full distribution/source wiring equalities and a local compiler query cap; global origin/binding and their numerical bounds remain open. Exact axiom guards allow only `propext`, `Classical.choice` and `Quot.sound`.
