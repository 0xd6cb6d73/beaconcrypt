# Uniform counter projection through protocol services

`PqxdhRecordFactsCounterProtocol.program_project` proves an exact computation equality for an arbitrary adaptive program over the actual `PqxdhRecordLiftProtocol.ServiceSpec`. It retains the entire program result and every private field except the uniform sampler count, which is projected to zero on both sides. It works from any initial private state and for any fixed mixture of real and ideal evolving-chain coordinates.

The new `interpreter` follows the original service dispatcher. Allocation performs the same lazy seed-table operation; explicit coin requests return the same sample; public hashing uses the real shared lazy ROM. Effect charges are unchanged. Hidden coordinate lookup, native opening and native sealing use the previously proved complete local callback projection. Caller-known sends and receives use the original source adapters and actual native programs, including optional writer results and optional plaintext. Publication moves the literal pending buffer into the same tagged produced log.

`primitiveWork_project` frames a projected native computation with the unchanged complete chain table. `interpreter_project` proves the equality separately for every service constructor, using the lower native, sampler, local and writer-log projection theorems. `program_project` extends it through any adaptive continuation with the existing checked state-projection simulation theorem. These are computation equalities before evaluating a final security decision; they do not depend on equality of marginal samples or assume that the protocol's selected key is honest.

The original source execution still charges all its samples. The counterless endpoint is used only for security observations that do not read that instrumentation. Source and reduction query bills are separate obligations; no uniform work is declared free and no equality of counters is claimed. Native and effect counts remain exact, as do seeds, whole chain outputs, shared cache, produced and pending frames. No cryptographic, codec, freshness or adversary restriction is added.

Three declarations have exact guarded axiom checks. The framing lemma uses only `propext` and `Quot.sound`; the service and adaptive-program equalities additionally use `Classical.choice`. The separate CTX interpreter join must connect the actual keyed callback to the counterless family endpoint before the private-cache discard theorem applies. Neither this module nor its lower projection module proves origin, binding or a statistical advantage bound. No Rust, primitive implementation, snapshot or persistence work is included.
