The final statements compare the actual `PrivateCacheWorld.erased` source handler with the existing selected muted handler. All service requests, optional replies and complete private state are retained. The proof introduces no primitive, codec, freshness or honesty assumption.

`marked` adds one analysis-only Boolean to the state. After each literal source call it records the disjunction of the earlier flag and `serviceBad` evaluated on that call's original input state. That deterministic flag follows the real opening gates and tests the actual selected replay reply. The handler continues to execute the original call and return its original reply, even after the flag becomes true. `marked_flag`, `marked_sticky` and `hit_marked` prove the exact update and monotonicity.

`marked_erase` and `complete_erase` prove exact program equality after removing only this Boolean, for one service and every adaptive continuation respectively. In particular, instrumentation never returns the flag to the adversary or changes how subsequent requests are selected. The selected dictionary, private suffix cache, shared hash cache, native counters, chains, seeds, produced frames and pending frames remain in the compared result. The result type can itself include the complete command transcript or any final decision. The source's optional plaintext is never replaced with an adversary-supplied target.

`agree_good` proves pointwise agreement at every complete good output. A flagged input step gives zero probability to every good output on both sides; an unflagged step uses the existing exact local source equality. `event_good` then gives equal unconditioned probabilities for every event intersected with the final good flag. It does not condition a distribution on acceptance or freshness. `bad_probability` proves equality of the complete bad-event probabilities, so a bound established in either experiment transfers to the other.

`marked_distance` applies the existing VCVio identical-until-bad theorem to the joint result and state. `complete_distance` removes only the ghost Boolean by deterministic projection. The resulting total-variation bound has coefficient one in front of the selected replay-match probability. No extra target, session or record selection factor occurs in this fixed-selected-coordinate comparison. A later selection argument must count its own loss.

They use the actual source crypto callbacks, universal decoder, counterless base interpreter and optional frame writer. Callers supply no protocol-security or simulation premise. Existing native/hash/KDF/reduction bills remain the source of numeric resource bounds; these theorems neither declare opaque work free nor identify the erased experiment's costs with the original counted `ctxRun` costs.
