# HB-85 adaptive CTX cache and resource interfaces

This checked milestone adds three scoped modules above the published adaptive nonce-AEAD and unclaimed-target CTX components. It preserves actual optional plaintext and complete hash caches across an arbitrary adaptive sequence of raw requests. It proves an exact canonical-to-routed-split cache projection, a separate key-free independent-public wrapper reduction to ordinary nonce-AEAD integrity, and explicit source/reduction query bounds. The two experiments have not yet been joined by the adaptive prefix-isolation and alias-guessing proofs, so this milestone does not state canonical adaptive CTX authentication or complete Stage 3.

## Raw interface and retained state

`AdaptiveCtxReceive.RawDecoder` is a supplied deterministic function from arbitrary bytes to an optional CTX target. The target contains the original nonce, associated data and record identifiers, ciphertext body, tag, and commitment. It contains no claimed plaintext. Decoder rejection returns `None`; a well-formed request first performs the private commitment lookup, compares the candidate commitment, and only then returns the base challenger's optional opening. The original raw bytes are delegated unchanged to the ordinary AEAD decoder. No plaintext is recovered to manufacture an adversarial target.

The private dictionary key is the actual 197-byte CTX suffix `nonce || associated_data || tag || LE64(sequence) || LE64(session_id)`. The ciphertext body is intentionally absent from this production commitment suffix; it remains part of the unchanged underlying AEAD target. A successful sealing call inserts or reuses that same suffix dictionary. Every well-formed raw verification also inserts or reuses its suffix before checking the commitment, including rejected verifications. The private-input log prepends every such operation, including cache hits. Malformed input increments the raw counter but performs no private hash. Nonce-rejected sealing performs no private hash. Complete public-query history, public/private caches, seal history, used nonces, private-input log, and raw counter are retained.

`privateStep_no_raw`, `publicStep_no_raw`, and `sealStep_no_raw` prove that the wrapper's internal work creates no hidden raw opening requests. `rawStep_raw_query_bound` permits at most one delegated opening per source raw request. `wrapped_raw_query_bound` therefore preserves the source bound `qRaw`; rejected commitments and malformed requests still count as source attempts even though they need no base opening.

## Exact shared-cache execution

`AdaptiveCtxCanonical.canonicalRaw` uses the actual shared classical random oracle at `key || suffix`, then returns the real primitive opening result. `splitRaw` performs the same computation against the suffix cache. `canonicalRaw_split` proves exact equality after projecting the complete final cache and retained instrumentation. This includes commitment failure, base opening failure, cache hits, and parser rejection.

`canonicalCtx_split` supplies the corresponding result for adaptive public-hash and sealing requests, including nonce rejection and the ordered private-input log. Its target is the routed split oracle: a public query beginning with the actual secret key is deliberately routed to the private suffix table. The secret key belongs to this challenger interpreter and is not given to the adversary. This is an exact change of state representation, with no key-prefix probability assumption and no loss term.

`canonicalImpl_split` combines every query case. `canonicalGame_split` then quantifies over the entire adaptive `OracleComp` continuation and proves equality of the full evaluated execution after state projection. Its result includes the adversary's arbitrary output and all retained state; it is stronger than equality of individual hash or key marginals. `canonicalRaw_attempts` proves an exact increment of one for every supported raw reply. `canonicalGame_attempt_bound` proves that any source program bounded by `qRaw` ends with a raw-attempt counter at most `qRaw`, regardless of parser rejection, repeated requests, failed commitment, failed opening, or adaptive stopping.

The primitive interface supplies total typed sealing and optional opening, and nonce uniqueness is enforced per key by the existing nonce-respecting sealing oracle. This does not assert that nonce byte strings differ across unrelated keys. The source decoder, raw byte parsing, ratchet state and persistence are separate boundaries below.

## Independent-public wrapper integrity hop

`AdaptiveCtxReceive.wrapped` is a key-free simulator using an independent public random-oracle cache and its private suffix dictionary. It uses only the ordinary primitive sealing interface and actual optional opening replies of the surrounding adaptive experiment. `linkedGame_eq` proves that linking its stateful implementation to the adaptive ordinary AEAD interpreter is exactly the wrapped ordinary AEAD execution, retaining both the complete wrapper state and the base state and ghost discrepancy flag. `uniformLinkedGame_eq` preserves this equality when the single primitive key is drawn uniformly once.

`uniformLinkedGame_distance_le_intctxt_sum` applies the existing adaptive one-key ordinary integrity theorem to this same wrapper. The total-variation distance between actual base opening and the log/reject simulator is bounded by the explicit sum of the constructed ordinary INT-CTXT forgers over indices `0` through `qRaw - 1`. Every forger stops before its selected raw reply, submits the unchanged decoded tuple, and simulates earlier replies only from its own successful encryption log. It does not obtain the challenger key or an opening oracle. Each ordinary challenger performs one final verification. There is no additional session-selection factor in this one-key statement; the finite sum pays for attempt selection.

This bound concerns the independent-public wrapper games. The exact canonical cache theorem targets a routed split game. A checked equivalence between the direct independent handler and the key-free wrapped real execution, preserving duplicated seal/nonce histories, is still required. Adaptive isolation of public queries that hit the secret prefix and adaptive commitment-alias guessing must then connect those experiments. In particular, a guessed alias whose base tuple was honestly sealed may receive the same plaintext in both ordinary AEAD games. The ordinary integrity bound does not charge that alias event.

## Explicit query ledger

`AdaptiveCtxQueryBounds` separates source uniform-oracle queries (`qCoins`), public hash queries (`qHash`), sealing requests (`qSeal`), and raw receive requests (`qRaw`). A source uniform request can select any finite uniform distribution; each digest miss specifically contributes 64 byte-valued uniform requests. The source bounds quantify over the same arbitrary adaptive continuation. `sourceWork_bound` proves that the latter three disjoint request classes use at most `qHash + qSeal + qRaw` requests; the underlying union theorem is valid even without disjointness. `wrapped_uniform_pair_bound` combines the uniform and work counters with their actual weights rather than bounding each by an uncharged ambient total.

Every public-hash request, successful seal, or well-formed raw verification can cause at most one 64-byte digest miss. Cache hits, malformed raw input and nonce-rejected sealing cost zero digest draws, but the stated bounds safely include them. `wrapped_uniform_bound` proves at most `qCoins + 64 * (qHash + qSeal + qRaw)` uniform-oracle queries. `wrapped_seal_bound` proves at most `qSeal` primitive sealing requests. `wrapped_raw_query_bound` proves at most `qRaw` delegated raw openings, while the exact canonical counter counts all source raw attempts.

`indexedReduction_bounds` transfers the uniform cap and the seal cap to every stopped ordinary INT-CTXT reduction in the finite sum. Each reduction has zero opening-oracle requests and one final challenger verification. A fixed attempt index requires no random selector query. Evaluating every member of the family would require up to `qRaw` separate primitive experiments. Primitive execution costs, canonical challenger key generation, and the full source/reduction running time are not identified with these query counts. These bounds cover the stated wrapper and reductions; they do not yet supply the global ratchet or multi-session ledger.

## Permanent contracts and remaining composition

The one-key primitive endpoint remains the existing correct nonce-AEAD sealing/opening interface and its ordinary INT-CTXT game. No primitive implementation or internal security proof is added. The canonical cache interpretation uses a shared programmable classical random oracle, which is an explicit idealization stronger than BLAKE2b collision resistance. The independent-public experiment is a separate hybrid, whose adaptive connection has not been assumed as a primitive guarantee.

Remaining work includes the direct independent-to-wrapper state relation, adaptive secret-prefix isolation including every failed private query, adaptive alias guessing with persistent repeated-guess cache entries, and the conventional IND$ simulation with a constructive fresh-nonce realization. Repeated failed guesses do not automatically receive independent new digests. The existing one-target CTX bound cannot be multiplied by `qRaw` without constructing and checking the intermediate adaptive simulations and their query accounting.

The production CryptoFrame decoder, complete-input behavior, executor field provenance, receive-key consumption, replay rejection, failed-open rollback, persistence restoration, multiple sessions, correlated evolving keys, permitted reveals and freshness rules remain required. Current-chain compromise exposes descendants and is not assigned post-compromise recovery by these components. Compiler correctness, native primitive contracts, storage integrity, rollback resistance, linearizable ownership/CAS, and deployment crash behavior retain their explicit external status. This milestone proves no symbolic correspondence by itself and does not replace the missing common computational/symbolic experiment.
