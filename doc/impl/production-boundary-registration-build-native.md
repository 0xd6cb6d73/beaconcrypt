# PB-05: native Server build and pending-token settlement

`PqxdhBoundaryRegistrationBuildNative` adds eight operational statements joining the Codex-reviewed extracted Server builder to the actual native registration scheduler and frozen CE `.build` command. It uses the original native tail interpreter and full state. It introduces no cryptographic contract, root-security premise or new experiment.

`native_exact` replaces only the original tail program by the equal extracted executor. `native_present` gives the complete evaluated distribution for a present token. It retains the supplied root, real primitive/cache work, original diagnostic settlement, exact Server update and original successful-inner-seal log. The pending slot is removed on all returned outcomes. The root-family cache/history, target Beacon, session counter and other ghost fields remain unchanged, as shown directly in the complete returned state. `native_missing` gives the exact no-op result for a missing token. `token_consumed` derives an empty pending slot for every supported outcome without an allocation, success or honest-target premise.

The original native ghost is preserved exactly. An inner writer failure has no new successful-inner-seal entry, while all native primitive/cache effects before it remain. An outer writer failure retains the successful inner seal entry and leaves the local candidate uninstalled. Registration does not append to the separate CE produced-record list; this proof does not invent an entry there. The preceding `PqxdhBoundaryRegistrationBuild` equality and failure theorem establish the builder's actual publication order and local-candidate behavior.

`scheduler_build` identifies the actual shared registration branch. `deployment_build` identifies the frozen CE native command. `deployment_complete` carries that equality through any continuation on the complete response and deployment state. It retains every owner, both native caches, raw-attempt counters and the produced-record list, including failure branches. No state projection, marginal distribution argument or erased endpoint is used.

`native_uniform` transfers the existing `PqxdhServerAuthNativeUniformCosts.native_build_uniform` bound of 64 finite uniform queries. It counts a possible 64-byte CTX table miss; a hit draws nothing. This is only the uniform-query bill. Real pure initialization, step HKDF, AEAD, native writer/codec calls, allocations, erasure and arbitrary continuation work remain at their original interfaces and are not declared free. No new total running-time claim or probabilistic assumption is inferred from the cap.

Together with `PqxdhBoundaryRegistrationBuild`, these statements close this narrow real builder-to-CE operational equation. The maintained deterministic `source_build_exact` and extracted candidate/first-send facts remain the source boundary; public Rust wrapper transcription, allocation/runtime, ownership and codec contracts stay separately recorded. They do not establish codec internals or change the registry/primitive contracts. Persistence and snapshots are outside scope. The same PB exclusion scans and live controls apply, including the exact previously reviewed functional HKDF source-field allowance only; the root Extract remains the existing shared CE ROM.
