## Limits

This is ordinary fresh-name secrecy with observable result bits and privately owned application plaintext. It does not prove observational equivalence, secrecy of arbitrary low-entropy messages, confidentiality for the actual public optional-plaintext oracle, post-compromise recovery, or arbitrary secret-dependent application behavior. It does not extend past the retained near bounds/cutoff. Public decryption with challenge messages still needs exact target-release/freshness policy, aliases/replay/cache handling, computational reductions, selection factors and query counts in the common experiment. Snapshot/persistence experiments and native codec internals remain excluded as directed.
