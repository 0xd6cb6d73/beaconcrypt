# Actual record-world counter accounting

This component connects the existing open-program request bounds to the counters returned by the executable `PqxdhRecordLiftWorld.run`. Those counters record source primitive calls, restricted effects and actual underlying uniform queries separately. All conclusions concern every supported result of that execution, retaining its actual shared cache, optional primitive replies and adaptive continuations. No production code or frozen World definition changes.

`weighted_support` proves a support-wise metric bound for two disjoint, selectively bounded request classes. Each class has its own cost, and every remaining request has cost zero. The proof follows every possible adaptive reply and threads the actual handler state. Applying costs one and 51 to sends and raw receives preserves `S + 51 * R`. The zero-cost remainder needs no cap, so the native derivation conclusion requires no environment `Frame` allowance. Here `S = caps.outer.sends` includes native, test and fresh sends across both roles, and `R = caps.outer.receives` counts both raw-receive routes, including rejected attempts.

`native_support` connects this transport to the literal `World.primitives` instrumenter. It unfolds the actual interpreter and records the selected native call once, while the optional primitive reply, uniform sampling and shared cache continue through the original computation. It applies to every source-native client with the corresponding query bound and every starting primitive state. It assumes no kernel reachability, successful opening, freshness, alias exclusion or cryptographic contract.

`server_native` and `beacon_native` instantiate the existing source send/receive bounds through the real handlers and frame logger. The administrative counter lemmas cover successful and refused installations, and `handler_native` charges every other request zero native work. `schedule_native` follows arbitrary adaptive continuations. `run_native` applies the previously proved joint send/raw bounds to the actual open program, and `run_kdf` establishes `native.kdf ≤ caps.derivations` with `Budget.Respects` only. The general native theorem also gives sealing and writer caps of `S`, an opening cap of `R`, and a native hash cap of `S + R`.

`native_effects`, `server_effects` and `beacon_effects` show that record execution preserves the separate direct-effect ledger. The outer effect wrapper increments its selected counter once for every request, including administrative refusals. `run_effects` transports the finite `Frame` allowance, keeping startup coins separate from direct adversary and wrapper coins. Combining these actual counter bounds, `run_hash` establishes `effects.hash + native.hash ≤ B.hash + B.sends + B.receives + caps.envTotal allowance .hash` with `Frame` and `Budget.Respects`. Both hash routes retain the single original CTX cache; the theorem counts their calls without replacing its hit/miss behavior.

Uniform accounting is separate. `sample_byte`, `sample_vector` and `sample_fixed_bytes` unfold the actual sampler and prove the exact number of underlying uniform queries. `sample_seed` specializes their product to the two 32-byte seed components: the returned seed is unchanged and the instrumented count increases by exactly 64. `resolve_miss_count` substitutes this equality into the existing exact hidden-resolution equation, retaining the whole World poststate: only the cached seed, lookup/draw counts and uniform count change. These equalities apply to any starting state with the specified slot absent and retain more than the marginal seed distribution. Direct coins cost one, shared-ROM cache misses cost 64 and hits cost zero; source deterministic KDF, AEAD and writer evaluation still appears in native call counters.

`primitive_uniform_bound` uses the existing actual shared-cache primitive query bound and deterministic source HKDF law. `native_uniform` carries the resulting accounting inequality through an arbitrary native program. The installation, capability, effect and record-handler lemmas then account for every World branch. `run_uniform_counts` starts from the actual empty World and proves `uniform ≤ effects.coin + 64 * (effects.hash + native.hash) + 64 * seeds.draws` without a `Frame` or adversary-budget premise. Its hash-call allowance is an upper bound that also covers cache hits; it does not replace the actual cache or charge a hit as an executed draw.

`cachedSlots` counts occupied slot indices, independently of any equality between sampled seed bytes. A missing-slot insertion increases that cardinality by exactly one. `SeedAccounting` expresses equality between additional fresh draws and additional occupied slots, including arbitrary starting caches. Every actual World request preserves it, and `schedule_seed_accounting` extends it through adaptive continuations. Starting from the actual empty World, `run_seed_draws` proves that fresh draws equal final occupied slots and are at most `n`. This finite bound is derived from execution, with no supplied reachable-state invariant, consistency predicate or seed-injectivity premise.

For `B = caps.outer`, `Ecoin = caps.envTotal allowance .coin` and `Ehash = caps.envTotal allowance .hash`, `run_uniform` combines those results with `Frame` and `B.Respects` to give `uniform ≤ startupCoins + B.coin + B.test + bounds.max * B.fresh + Ecoin + 64 * (B.hash + S + R + Ehash) + 64 * n`. The startup count, wrapper test/fresh coins, restricted environment work, record hashes and hidden seed draws all appear explicitly. The slot count remains the finite parameter of the supplied World; this theorem does not identify it with a CE registration budget.

This is source execution accounting. It does not bound running time, parsing or copying, and it does not account for a selected cryptographic reduction's extra work. CE still proves its environment allowance and source/erasure joins. Chain-key replacement, selected reductions, nonce and alias losses, final origin/hiding events and later-phase budgets remain separate obligations. No frozen module or production Rust is changed.
