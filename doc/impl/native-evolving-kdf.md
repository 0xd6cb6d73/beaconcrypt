## Remaining live-source obligations

The actual reached source cut, its concrete public and live-value candidate trace, and live-disclosure stopping/event transport remain to be connected. The selected random handler is not yet an everywhere-consistent same-address random table: a known input, including a newly returned chain, can equal the selected bytes. That comparison needs its explicit alias/guess event. The initial first32 chain also shares the material-key projection and needs its own correctly scoped cut; it cannot be declared unavailable while that coordinate remains in the observer.

The earlier full-output table contains input and next-chain bytes and remains private proof state. It cannot be passed wholesale to a secret-input observer, exposed as a network/reveal capability, or erased without an exact state relation. Permitted prior identity, KEM, root and live ancestor knowledge must retain its consequences. Current-chain and skipped-key reveals remain actual operations. A live-reveal service may read only secrets still present in the actual native phase; disposed roots and InitSent secrets must not be recreated. Earlier authorized knowledge persists in history. Physical erasure and native-library/compiler/runtime realization remain explicit external contracts.

Snapshots, storage persistence, restoration and consequences of retaining old saved secrets are excluded from the requested proof. They are not deferred obligations. Private simulation state is not a snapshot capability.

No new primitive or protocol-level security assumption is introduced. This checkpoint proves source interpretation, a specified stopped-game reduction, and an explicit uniform-sampler fact. It does not establish evolving-key secrecy, a final finite-key family instantiation, forward secrecy, cross-owner agreement, a classified global ProVerif result or the full protocol objective. Deterministic HKDF/HMAC, table lookup, byte processing, source control and interpretation work remain accounted for separately from logical oracle calls and uniform sampling.
