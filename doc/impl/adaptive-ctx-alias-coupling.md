# Adaptive CTX optional-plaintext and private-cache coupling

This HB-85 extension connects the checked final-vector private-dictionary bound to every actual adaptive raw attempt. It proves a complete-state comparison for one fixed record key: the canonical shared-ROM CTX receive experiment is close to an experiment that returns plaintext only for an exact previously issued full CTX tuple. The adversary supplies the original raw bytes and receives the actual optional plaintext in the canonical game. All sealing operations, public hash requests, private lookup effects, rejected attempts, successful-record logs, nonce histories and counters remain in the compared state. This is a one-key cryptographic interface theorem; consuming ratchet state, correlated evolving keys, native decoding and the common multi-session experiment remain to be connected.

For source caps `qHash`, `qSeal` and `qRaw`, with `qSeal < 2^96`, `AdaptiveCtxAliasCoupling.canonical_replay_distance_bound` proves that the complete canonical-to-replay total variation is at most the following explicit sum:

```
AdvIND$(validationReduction)
  + qHash / 2^128
  + 2 * sum (i < qRaw) AdvINT-CTXT(indexedReduction i)
  + qRaw / 2^512.
```

The first reduction is the existing conventional Boolean nonce-AEAD IND$ adversary from `AdaptiveCtxPrefixValidation`, including its constructive fresh-nonce empty-message validation seal and finite candidate-tag scan. Each integrity adversary is exactly `AdaptiveRawNonceAead.indexedReduction` applied to the same `baseDecoder`, supplied fallback and `wrapped` source client. The two copies of that identical indexed family remain explicit: one pays for changing the opening replies, and one pays for transferring the public-prefix candidate event. The new final term pays for every private commitment-guess attempt once. There is no hidden honest-target or fresh-private-cache premise, and no extra record-position square.

The final comparison returns the plaintext of a successful sealing request only when the submitted nonce, complete CTX context and encoded record match that issued tuple. These are plaintexts already supplied by the adversary to the sealing interface. The canonical side instead returns the real opening oracle's optional plaintext through the previously checked ordinary integrity simulation. A secretly recovered plaintext is never inserted into a target, and a changed commitment or changed outer context is not silently relabelled as an issued record. This comparison permits repeated exact issued tuples because the cryptographic component has no consuming ratchet owner; protocol replay rejection remains an explicit next layer.

`AdaptiveCtxStoppedRaw.stopAtRaw` constructs the client stopped at one raw position. It forwards every earlier request and its actual reply unchanged. At the selected position it first executes the original raw request, including its private lookup and counter update, and then returns the original raw bytes without running the remaining continuation. A malformed request still occupies that position; an absent position returns no candidate. `stopAtRaw_query_bound` preserves every declared query class, so the selected operation and all preceding work are charged.

`CachedGuess` is an event on the actual terminal source cache. It requires an unchanged selected target, full-tuple freshness, an issued base tuple, and the submitted commitment already installed at the target's exact private address. `cachedGuess_implies_completed` transports this event to the same completed private table used by the published deferred-sampling proof. `cachedGuess_bound` then applies the checked final-vector bound without replacing the actual failed-query cache by an honest-only cache. Installed cells agree with every completion of that same cache. The huge total table remains an analysis device, never an enumerated reduction or a free runtime operation.

`oneSlot` extracts the decoded selected raw request into a one-entry optional vector. `stopped_guess_bound` applies the one-entry bound to each stopped source execution, giving `1 / 2^512` for that position. Repeated guesses and previous failed lookups are retained. `firstDiscrepancy` is a challenger-side monitor over the actual replay comparison. It checks the post-lookup state and stops at its first eligible accepted guess; earlier responses, coins and cache states are the real ones in that comparison. `firstDiscrepancy_le_indexed_sum` proves its probability is bounded by the sum over all `qRaw` stopped positions, from any prior state. `firstDiscrepancy_bound` starts from the actual empty source state and sums the one-entry bounds, yielding `qRaw / 2^512`. It does not apply a `qRaw`-entry bound separately at every position.

`AdaptiveCtxAliasCoupling.postLoggedReply` reconstructs the prior logged-world response using only the actual installed private cell and the successful base sealing log. `loggedRaw_eq_replayRaw` proves equality of the full evaluated raw kernel: both sides perform the same private lookup and retain the same poststate; only the returned optional reply changes. This equality also covers malformed input, cache hits and failed commitments. `replayRaw_preserves_invariant` and `replayImpl_preserves_invariant` retain actual issued commitments, marked and unique per-key sealing nonces, and base-log correctness. These invariants permit cache entries created by rejected raw requests.

`replayRaw_discrepancy_iff` proves that the logged optional reply differs from the replay reply exactly at the monitored post-lookup event. Its proof uses actual cached commitments, unchanged submitted bytes and the previously checked full-tuple/base-tuple classification. It assumes no symbolic constructor injectivity or unexplained cache freshness. The fixed-width CTX encoding facts and per-key nonce uniqueness used by the private-dictionary proof remain the existing checked source-interface facts.

`flaggedImpl` adds one sticky analysis bit to the common raw kernel. On the logged side it returns `postLoggedReply`; on the replay side it returns the actual replay reply. The bit records a reply discrepancy, and all other state is unchanged. `flaggedImpl_agree_good` proves equality of complete next-answer/state probabilities while that bit is clear. `flaggedImpl_bad_mono` and `flagged_bad_probability_one` preserve a previously raised bit even if later adversarial continuations diverge. `flagged_bad_eq_first` identifies the replay world's final bit with the first-discrepancy monitor, using the reachable invariant at each actual query.

`flagged_query_projection` and `flagged_run_projection` remove only the ghost bit and recover each exact full source distribution. They quantify over arbitrary complete adaptive continuations, rather than comparing reply marginals. `flagged_bad_eq` applies the output-bad equality to the two full kernels. `flagged_distance_bound` then bounds their complete output distance by the first-discrepancy probability; `source_distance_bound` removes the ghost bit and retains the actual full private cache, transcript and optional replies. `retained_distance_bound` samples the same key in both worlds and retains it jointly with the complete terminal source result only for analysis. The key never becomes an adversary reveal.

The capstone joins that last bound to the existing complete-cache canonical-to-logged theorem by total-variation triangle inequality. It uses the same sampled key and the checked `retainedDirectLoggedGame_eq_client` equality, so it does not drop key/transcript correlations between the earlier prefix/integrity hybrids and this private-alias hop. The classical programmable hash-ROM interpretation remains stronger than collision resistance; no collision-resistance-only claim replaces it. All primitive algorithms and implementations remain contracts, with no internal primitive proof attempted.

`AdaptiveCtxAliasQueryBounds.flaggedImpl_uniform_step` and `flaggedRun_uniform_bound` charge both complete sticky kernels at most `qCoins + 64*(qHash + qSeal + qRaw)` uniform-oracle requests. Source `qCoins` requests may have arbitrary finite ranges; each actual digest miss contributes 64 byte-valued requests, and a repeated lookup reuses its cell. `stoppedRun_uniform_bound` gives the same conservative cap to each selected comparison, including the selected raw operation. `retainedReplayGame_uniform_bound` separately adds all 32 key-byte draws. `replayRaw_raw_count` and `replayImpl_raw_count` prove exact per-operation counter changes, and `replayRun_raw_bound` bounds every complete adaptive run by the prior counter plus `qRaw`.

The unchanged integrity reductions each have at most `qSeal` sealing queries, one final verification and `qCoins + 64*(qHash + qSeal + qRaw)` explicit uniform-oracle queries, by `AdaptiveCtxQueryBounds.indexedReduction_bounds`. The conventional validation reduction has at most `qSeal + 1` seals and the same explicit uniform cap, by `AdaptiveCtxPrefixValidation.validationReduction_seal_bound` and `validationReduction_uniform_bound`. Its complete real challenger additionally samples 32 key bytes. The ordinary random challenger separately samples each successful ciphertext body and sixteen-byte tag, so its complete byte-sampling ledger needs an explicit total submitted-plaintext-byte budget; a seal-count cap alone does not bound that work. This remaining accounting refinement is not hidden inside the displayed reduction-query counts.
