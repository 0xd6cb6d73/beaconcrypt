# Ordered publication capture at the source interface

`PqxdhServerAuthPublicationCaptureSource` connects the actual dynamic known-key interface to the ordinary reference decision used by the [privacy bound](server-authentication-publication-privacy.md). Its `dynamic` observer retains the actual optional selected seal reply and stops the first selected raw request before issuing it. It forwards every other query and its actual reply, including complete known-key operations whose bytes may equal the selected key. The extra retained copy is private observer state; the source continuation still receives its original selected seal reply.

`capture_prefix` proves that a complete ordinary prefix containing no selected seal or raw request executes unchanged before capture continues. `lower` applies that fact to the actual known-key reduction and handles every selected query directly. The resulting oracle-program equality identifies the same ordered selected record and raw candidate on both interfaces. It does not identify occurrences by decoding writer bytes, by ciphertext equality, or by assuming records are unique. At the result boundary it projects the reduction's final local bookkeeping; every underlying oracle query and reply, and every intermediate known-key history used by the continuation, remains in the execution.

`decision_lower` and `reference_decision` give the exact Boolean client for the fully sampled mixed reference. `reference_view` then consumes the existing complete dynamic source/challenger interpretation theorem: the selected-key source game is exactly the canonical ordinary view of the checked reference decision. Both original context/residual samplers and the selected-key sampler remain unchanged. `capture_probability` preserves the component's full terminal state inside the experiment while relating the Boolean decision to the event on its actual captured pair.

`reference_bound` bounds the actual dynamic reference capture event by the transparent `PublicationPrivacy.loss`, using only the same concrete KEM bounds and original four adversary budgets. Thus the dynamic event has the already checked two ordinary IND$ advantages plus `H / 2^128 + 1 / 2^128`, with `H = entryReductionBudget + 76` and the previously proved primitive/challenger bills. No selected occurrence, first-seal, quiet-suffix, writer-failure, or tag-independence condition is supplied by the caller. The capture adds no oracle requests, and its ordinary reduction is literally the previously checked decision rather than a separate client with unproved budgets.

The remaining source-publication consumer must still associate an actual accepted record with the relevant selected seal and unsuccessful public build occurrence, using the maintained receipts and the separate actual/reference failure coupling. This module does not assert that every accepted record was published, or that tags are uniform after conditioning on failure. The original B event, ProVerif queries, primitive contracts, and codec boundary remain unchanged. Full privacy for the actual unpublished event requires its event inclusion and the new accepted-observation source/key-schedule transport.
