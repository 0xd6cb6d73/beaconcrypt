The mathematical `project` operation reinstalls that cache while retaining every source field, pending token, installed kernel, mark, table entry, public transcript, seal log and private annotation. `Ready` is the sole per-query source-comparison condition: if the actual query builds a marked session whose pending token is present, the selected component's used-nonce list must initially be empty. Other queries require no additional condition. This is an operational obligation for the surrounding stopped scheduler, not an honest-target, authentication, primitive-security or successful-build assumption. The complete original handler can contain several marked sessions; this local module does not assert the condition throughout an unrestricted run.

`settle` installs the exact original one-shot designation and sticky omitted-table rejection after the full callback. `handler` selects the designated implementation precisely when the previous designation flag is false and the original query/phase/counter test designates this operation. Later calls use the ordinary derive service while retaining the same hidden-entry table. The native optional failure inside a normal reply remains distinct from outer component refusal, which stops the compiled continuation.
