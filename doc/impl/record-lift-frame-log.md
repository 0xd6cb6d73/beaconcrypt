# Produced frames through the CTX sealing adapter

`PqxdhRecordLiftFrameLog` closes one operational gap in the record-layer CTX compiler. The existing selected/known sealing adapter returned only the optional writer result, whereas the common deployment experiment records every frame handed to the writer, including a frame whose writer then fails. The sixteen theorems preserve that exact frame list along with the existing optional result, shared hash cache and selected-component histories. This is a local adapter equality and query-accounting result; it is not the global adaptive record security theorem.

Production `beaconcrypt/src/ratchet.rs:371` computes the detached ciphertext and tag, builds the commitment, fills the frame's ciphertext, sequence and sender fields, then serializes it. Serialization can return no public ciphertext after a complete frame has been produced. `PqxdhDeploymentNative.frameLog` logs precisely this writer input. `native` runs that literal logger over the existing source seal and source primitive lifts. `native_valid` equates its complete result with the typed CTX computation, preserving an arbitrary auxiliary state and the complete shared hash cache. `native_invalid` proves no produced frame and unchanged state for invalid associated-data width in the existing total functional AEAD presentation. The local AEAD operation still occurs; it is not declared free. `native_complete` covers both cases in one equation.

`typed` returns `(writer frame, [frame])`, or `(none, [])` for invalid associated-data width. `typed_forget` removes only the returned log and recovers the existing typed seal before interpretation. `selected` obtains the protected record from the selected challenger and constructs the original frame from that returned record; its program contains no selected key. Its `none` reply is an explicit `repeatedNonce` stop with no frame. A known-material seal instead remains the real local seal with its original public hash forwarded to the same shared cache. `selected_forget`, `known_forget` and `call_forget` recover the prior callback programs exactly, including selected refusal and writer failure.

`selected_fresh` is a complete-state equality under the explicitly stated selected nonce condition: the nonce has not appeared in that component's actual sealing ledger. It retains the record returned by the real selected challenger, the full cache, successful-seal and nonce histories, raw-attempt count, private suffix history and every other dynamic entry. The frame enters the returned log even if its writer returns `none`. `selected_repeat` preserves the entire state and returns the separate stop; it does not relabel that stop as a production rejection. These theorems do not prove nonce freshness for the global protocol. Establishing the relevant per-key source invariant or bounding the actual stopping event remains part of the record lift.

`known_complete` retains the same full dynamic state while routing the real local seal's hash through the selected component's public shared oracle. It assumes neither different key bytes nor different nonces, so known/selected aliases are allowed by the equality. `known_cache` and `selected_cache` project only the added analysis histories, retaining the produced list and entire hash cache. `call_cache` combines the branches for every input; its freshness premise is needed only for selected material with valid associated-data width. `native_source` then compares this callback directly with `native` under the original mixed primitive interpreter, preserving arbitrary auxiliary state alongside the cache. The KDF handler is arbitrary because sealing itself makes no KDF call, not because KDF work is ignored globally.

`call_bound` transports any predicate-based oracle-query bound without changing it, since forgetting the returned frame list recovers the exact prior query tree. `call_bills` states the concrete four classes: a selected seal attempt has at most one target sealing query and no explicit public hash call; a known seal has at most one explicit public shared hash query and no target seal; both make zero raw-verification or explicit uniform queries in this callback. The selected attempt is counted even when refused. Hash-cache misses and random draws inside the challenger remain charged by its interpreter. The local AEAD and writer operations remain real deterministic calls and must be counted by the surrounding native ledger. No claim treats them, environment work or other protocol callbacks as free.

The source equation retains logs before publication, rather than identifying production with successful public output. It adds no primitive assumption, codec property, decoder agreement, independence claim or cryptographic advantage bound. It uses the existing total functional primitive presentation and exact source effect definitions. It does not prove the complete dynamic-world simulation, per-key nonce uniqueness, target-key distribution, receive acceptance accounting, ordered multi-key replacement, alias or refusal probabilities, or ideal-world origin and hiding. Those joins must use the same global experiment and its observable event projection; arbitrary private-state predicates are not security observations.

Every theorem has an exact axiom guard. Source, artifact, query bounds, review and focused publication checks are recorded in `doc/impl/proof-receipts/record-lift-frame-log.json` when this stage is published. No Rust implementation or frozen proof module is changed.
