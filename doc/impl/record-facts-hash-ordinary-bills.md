# Complete source ordinary digest-query bill

`PqxdhRecordFactsHashOrdinaryBills.source_ordinary` bounds ordinary digest requests of the complete initialized `HashSource.compiler` by the existing `PqxdhRecordLiftIdeal.sharedHashTotal`. An ordinary request is exactly a combined-oracle query at the full byte-string address, separate from private `(material label, outer suffix)` addresses and finite coins. Every logical request is counted before memoization, so repeated inputs are included even when the digest interpreter later reuses a cached result.

`logged_total` retains every native callback and writer-log update while transporting the original native hash-call bound to the exposed shared-hash program. It uses the actual frame-log query-preservation theorem and the checked native compiler's per-call cost. `native_total` forwards each exposed hash request through the concrete shared compiler at cost at most one. `native_ordinary` then restricts that total bound to the ordinary address category. The caller-known send and receive cases use the existing complete source hash bounds, including exhaustion, cached and future receive paths, commitment failure, optional AEAD opening and writer failure. Public functional HKDF and AEAD calls remain real and retain their native charges.

`coins_ordinary` proves that the full finite samplers issue no ordinary digest query. `sealing_ordinary` proves that every hidden sealing branch issues only its addressed private digest request and finite coins; it therefore has zero ordinary requests. `query_ordinary` checks all ten concrete compiler constructors against the already defined source hash-category ledger. The ledger is conservative: its existing allowance for hidden opening and sealing is retained even though these erased compiler branches have zero ordinary queries. No additional attempt is omitted from the separate private or raw ledgers.

`program_ordinary` transports those per-service bounds through arbitrary complete stateful adaptive continuations with coefficient one. `source_ordinary` applies the existing `Frame env startup allowance`, outer `budget.Respects`, complete source program category bound and checked `hash_bill` identity. It includes environment effects, public hashes and caller-known record work. The `decisionCost` parameter occupies the existing bill record's field; the shared-hash total does not charge finite-only decision work as a hash. The theorem has no selected target, honest-key, freshness, successful-writer or mode premise. Its syntactic scope is separate from the replay/random restriction on the source-view equality.

Together with `HashPrivateBills.source_private`, this supplies the two global digest-category caps for the subsequent combined-cache collision argument. The module does not itself prove a collision probability or the final source binding/origin event. Uniform draws inside digest interpretation, complete finite-coin costs, native/source instrumentation and the eventual reduction resource bounds remain separate obligations. No primitive, deployment or protocol-security assumption is added, and no Rust or registration behavior changes.
