# Charging completed and cached later-record outcomes

`PqxdhLaterCommonRisk.authenticated_common` bounds the probability that the actual later-record sampler returns a true inner completed or cached decision. For a selected source record number `depth + 2`, the bound is `Σ (j + 1) / 2^256` over `j < T`, where `T = 7 + 67*qPost` and `qPost` is the sum of the original authenticated source certificate's Post request allowances. The result applies to either selected role. It adds no primitive security assumption, honest-target premise, arbitrary final-observer bound or assumption that the selected input is absent from the cache.

The deterministic starting point, `cached_beyond_cursor`, compares two walks in the same actual private table. If that table records a publication strictly beyond the retained cursor, the cursor input itself must already be present. `carried_invariants` preserves both the original directional lineage and cursor-depth bound through the complete source prefix, including unselected and failed callbacks. `complete_supported` identifies a completed cut with a supported outcome of the identical full source execution. These facts let `source_complete_risk` derive a non-clean cursor from the literal successful publication event and the source's empty initial trace, rather than assuming an arbitrary caller's trace is authentic.

`source_common_risk` joins this completed case with the pending cached case. On a pending cut, the maintained source-selection theorem identifies the descriptor address with the same retained cursor. Both branches are therefore subsets of one event in the same chronological source run, and the existing cursor-collision theorem is used once. There is no factor two for these two branches. Source initialization supplies the empty table/log and initial cleanliness; no collision-free history is postulated.

`prepared_common_risk` consumes the actual audited prepare/collect implementation. On a complete cut, its original pure source decision can be true only if the original publication gate holds. On a pending cached cut, the entire original continuation and its freshness decision still execute; their true probability is bounded by the probability of reaching that cached cut. An uncached cut returns its saved descriptor instead of a common decision. Audit erasure preserves the literal original source distribution and complete reached state.

`sample_one_common` instantiates this result on the actual root-free source input and initial response. `sample_inner_common` then averages over the unchanged prior preparation and full initial 64-byte draw. Every common, cached and pending branch remains in its original sampling order. `innerCommon` selects only the inner completed/cached result; the earlier root-preparation common result is a separate mass term. Finally, `authenticated_common` obtains the selected record position and the all-reply Post allowance from the actual authenticated preparation and its original certificate. Neither property is left as a new whole-protocol premise.

The nine public statements have exact standard-axiom guards. This module performs no new cryptographic operation and adds no constructed primitive advantage. Its statistical term counts the existing chronological private-input collision event, not all cryptographic work. The full prefix, public HKDF, cached suffix, external callbacks and original source generation keep their existing `LaterSharedMessageResources` and authenticated-source bills. In particular, this observation does not remove the 184 sampled pre-key bytes, the selected key draw or any base/decapsulation work.

This closes the inner common-mass obligation. It does not bound the remaining missing-parent record observer, prove target/parent address separation or establish later-record security by itself. The earlier `LaterRecordTarget` checkpoint separately retains and bounds the outer root-completion mass. The existing final-material statistical allowance also pays a different normalization/hybrid obligation; this new event bound does not silently cancel or reuse that allowance. Final composition must show both terms in the exact chain of inequalities. The original authenticated preparation's capabilities, reveal rules and certificates remain in scope; unrestricted joint scheduling is separate work. There are no snapshot, persistence or serialization-implementation claims.
