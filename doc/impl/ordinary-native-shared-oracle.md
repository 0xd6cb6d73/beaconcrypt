# Ordinary prechallenge callbacks with the actual shared oracle

`PqxdhOrdinaryNativeCache` and `PqxdhOrdinaryNativeSharedRom` compile the literal ordinary Beacon native callback used before the selected KEM challenge. They preserve the local auxiliary state, the complete joint identity state, every optional result, and the commitment random-oracle cache. Selected-key decapsulation uses the original local unblocked KEM interpreter. Root and initializer calls use the real fixed HKDF source. This is distinct from the maintained postchallenge callback that blocks the selected challenge ciphertext.

The cache module first relates `PqxdhPhase2SourceScheduler.ordinaryNative` to its actual native source interpreter, including the existing KEM-handle translation. For each non-raw callback it proves that changing only the incoming CTX cache changes only that same component of the result. The local callback is concretely defined by running the original callback at the empty CTX cache and projecting it away. The proof of independence justifies this factorization; it is not an assumption about arbitrary user callbacks. Its remaining local state contains both the original auxiliary state and the complete private identity pool and histories. Selected KEM decapsulation still executes its actual base-oracle computation, including rejection.

The raw branch is the original native KDF, hash and AEAD-open service. Its shared-oracle compiler returns the same real fixed-KDF response, forwards the same commitment input bytes, and returns the actual optional plaintext from the native opening. It does not recover or insert a plaintext into a supplied target. The functional native primitive presentation retains the existing perfect functional primitive and total ROM contracts; it does not establish primitive implementation correctness or arbitrary native callback availability.

`step` identifies a single compiled query with the complete original ordinary callback. `program` extends the equality to any adaptive native query program and retains the cache produced by actually executing its prefix. `original` identifies that distribution with the literal source `ordinaryNative` program evaluated through its existing local prechallenge KEM interpretation. This compiler has no selected message key. Its local selected KEM secret is an interpreter parameter, as appropriate for the later CTX reduction; these equations alone are not a selected-key KEM reduction.

`raw_bills`, `local_bills` and `bills` retain the complete cost of all source callbacks. Raw native calls use at most one hash and no uniform request. Non-raw calls use no CTX hash and forward every original uniform request through the common uniform interface. If an adaptive native client makes at most `qCalls` calls and every non-raw local callback has complete uniform allowance `qLocal`, `program_bills` gives at most `qCalls` hash calls and `qCalls * qLocal` uniform calls, including rejected calls. The supplied allowance is for the actual complete source computation, not a zero-cost ambient oracle. These query counts do not bound deterministic work, byte lengths, codec cost, allocation, or runtime; those remain the existing primitive and adapter cost contracts.

The existing generated/prior KEM encoding is retained exactly, including its single selected KEM scope. The result does not authorize collapsing arbitrary generated private KEM handles onto a selected key. The indexed KEM pool and its separate selected dispatcher must supply their own ownership and routing proof. Lifting these native callback equations through the full ordinary scheduler, borrowed selector, initial root experiment and global application interface remains a consuming obligation. No authentication, freshness, hidden-input pseudorandomness, nonce uniqueness or end-to-end secrecy follows merely from this operational compilation. All public fixed HKDF evaluations remain real, and no public-HKDF random-table interpretation is introduced.
