# Actual native Phase2 resource accounting

`PqxdhLivePhase2PrivateBounds.lean` supplies five checked resource statements for the concrete native owner from `PqxdhLivePhase2PrivateRoot.lean`. These statements count the actual executable callback programs, including rejection branches and the private ordered decapsulation log. They do not infer query bounds from equality of output distributions.

Let `qLocal` bound the uniform calls in each original local codec, point-conversion or owned-DH callback. Let `uDecap` and `bDecap` bound the uniform and base-oracle calls in each ordinary other-index KEM decapsulation program. These are resource bounds for the explicit primitive interface, not cryptographic security premises. The actual shared raw callback draws at most 64 uniform bytes for its CTX hash interpretation; real fixed HKDF and the trusted functional primitives remain present as local computations.

`auxiliary_uniform` proves a bound of `max(max(qLocal, 64), uDecap)` for each concrete auxiliary callback. `auxiliary_base` proves a bound of `bDecap` for its base requests. The previously checked typed other-index router proves that these callbacks issue no selected-key logical decapsulation. Correlated identity DH uses the current indexed seed and preserves its joint history; identity creation is outside this owner operation and is not made free by these bounds.

`private_owner_classes` applies the actual source owner partition. One full attempt uses at most `69 * max(max(qLocal, 64), uDecap)` uniform requests, `69 * bDecap` base requests, one selected-key logical decapsulation and one private-root request. The 69 factor is conservative: it charges the full native callback allowance. Optional decoding failures, inactive owners, rejection, raw receive work before the initial sequence-one check and terminal publication are included. The result still contains the complete updated owner, auxiliary state, shared cache, joint state and private attempt history.

`ordinary_owner_queries` transports any resource predicate through the exact private-log erasure equality and the ordinary root interpreter. `ordinary_owner_classes` therefore preserves the same uniform/base bills and at most one selected-key logical decapsulation. The root interpreter does not issue a second ordinary decapsulation: it uses the supplied challenge shared secret privately when the exact challenge is encountered and keeps public challenge decapsulation blocked. Its real fixed HKDF computation is still present.

These five statements do not yet charge a whole replicated execution. The consuming scheduler must add every repeated finish attempt, earlier source callbacks, identity and KEM creation, reservation draws, publication, record/public operations and explicitly permitted disclosure work. Challenger key generation and encapsulation, any final statistical or selection loss, the actual authenticated selected target, and event-specific freshness are separate obligations. Arbitrary callbacks or initial histories can contain aliases or prior knowledge; the absence of a selected-secret argument in the compiler is not a global nonexposure theorem. There is no snapshot or persistence experiment in this package.
