# Literal paths for the selected replay marker

`PqxdhRecordFactsOriginOrdinalMarkedPath` connects the existing actual adaptive marker interpreter to literal supported source paths. Its `Flagged` relation retains each original typed callback reply, complete pre/post state, attempted-label history and chronological sealing-cut list, together with the exact initial and final analysis flag. Each step updates the flag by the same `before || serviceBad target decode query state` expression used by `OriginMuteAdaptive.marked`. It adds no new protocol operation or adversary capability.

`erase` forgets only the flag and recovers the existing literal `Path` with the same complete cut list and final result/state. `lift` decorates any particular literal path with an existing final flag, preserving that path’s callback replies and states. `flagged_support` shows that a flagged path produces its exact complete marked output. These forward facts alone would not justify a protocol event bound for every marked execution.

`support_flagged` supplies the converse needed by that universal obligation. Every supported marked output has a literal flagged path with exactly that output, complete state and final flag, and a concrete chronological cut list. It recursively opens the same interpreter calls, retains their actual supported replies and follows the original adversarial continuation. `support_iff` states both directions together. The proof does not identify two paths merely because they have equal final results or states; it supplies an actual path for each particular supported marked outcome.

`sticky` proves that a true flag at the beginning of a flagged path remains true at its end. `hit_suffix` applies this to a continuation whose initial flag is the literal update at a callback where `serviceBad` is true. It does not manufacture a matching callback or plaintext: the consumer must establish the actual callback and its `serviceBad` condition. These facts operate on the complete same flagged suffix, not a separate run.

`prefix_lift` decorates the existing exact literal `Prefix` once. It returns its intermediate flag and quantifies over every compatible flagged continuation from that exact operational state. Joining the prefix and continuation retains the original chronological concatenation of cut lists, all callback replies and the complete final result. It does not claim an arbitrary marked execution followed a previously chosen unmarked prefix.

The downstream unpublished-record argument must still derive the accepted-receive-to-selected-match condition on the actual path for every supported marked resumption. These operational equivalences make that obligation expressible; they do not discharge it or close the numerical `OriginStatement`. The existing `resumeMarked` predicate also retains the selected writer’s literal failure condition, which this module neither assumes nor replaces.

The module has eight exact axiom guards and no new primitive, deployment or codec contract, no statistical term and no new query allowance. Original native, hash, finite-draw, raw-receive and source bills remain charged. No Rust, ProVerif, snapshot or persistence scope changes.
