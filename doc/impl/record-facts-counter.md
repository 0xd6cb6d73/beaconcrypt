# Uniform counter projection for record computations

`PqxdhRecordFactsCounter` proves eleven operational equalities needed before removing discarded private-cache queries from the record security observation. The only projected field is the count of uniform sampler calls. Native calls, effect counts, shared hash-cache entries, seeds, complete chain outputs, pending writer frames, produced frames and all actual replies remain in their original fields. These lemmas do not equate source costs or give a cryptographic bound.

`zeroPrimitive`, `zeroLogged`, `zeroRecord`, `zeroPrivate` and `zeroCtx` set that count to zero in the respective existing state. The computational endpoint `primitives` performs the identical native primitive program, retains its actual shared-ROM poststate, and charges the identical native call. `primitives_project` relates it to the counted original; `primitive_program_project` extends the equality to an arbitrary adaptive native program. The construction uses the existing counted-sampler forgetting theorem on the complete evaluated computation, not an equality of marginal samples.

`sampled_project` preserves an arbitrary probability program's entire result and all other private fields. `logged_project` and `logged_program_project` lift primitive projection through the real frame logger, including frames whose writer returns failure. `send_program_project` and `receive_program_project` use the actual source adapters; in particular a receive still returns its actual optional plaintext and a send its actual optional writer bytes. These equalities do not insert a recovered plaintext into a supplied target.

The `lookup` endpoint performs the same real or ideal coordinate lookup and native KDF charge. Ideal table hits reuse the whole stored output; ideal misses sample one whole 76-byte output, and real coordinates use the original real table function. `lookup_project` covers every mixture, seed map, coordinate and initial table. `liftLookup_project` additionally keeps the literal pending writer log. `local_project` combines this lookup with the actual native opening and sealing callbacks, retaining the complete chain table and all native effects. `withRecord_project` then lifts a projected record computation through the source's `recordState` and `putRecord` operations without changing unrelated private fields.

There is no new primitive contract or honest-key premise. These are deterministic computation equalities over the unchanged setup and source programs; they do not assume security or supply `OriginStatement` or `BindingStatement`. Counter projection is solely an observation step. The original uniform-query bounds remain obligations on the counted source and every constructed reduction. Full service and CTX interpreter projection, and the subsequent private-cache family composition, are separate consuming joins.

Each theorem has an exact guarded axiom check. Nine use only `propext`, `Classical.choice` and `Quot.sound`; `sampled_project` and `withRecord_project` use only `propext` and `Quot.sound`. The direct Lean 4.34 module check has no diagnostics. No Rust, primitive implementation, ProVerif, snapshot or persistence behavior is changed.
