# Source query ledger for the before comparison

The complete guard-free before reduction now has a checked query ledger derived from the original source interfaces. `PqxdhLaterChallengeSourceBills.pair` supplies the actual prelude bounds to the two ordinary CTX privacy reductions. It does not ask for a whole-observer or successful-cut resource premise. This complements [the source-derived continuation allowance](later-challenge-source-allowance.md); source-event freshness, nonce refusal, address aliases and other phase cases remain separate security obligations.

## Complete continuation and original callbacks

Let `q` be the sum of the adversary's existing per-kind `AdvBounded` budget. The earlier source certificate proves that both complete saved wrappers fit `1 + q`. Let `c` be the original `PqxdhAuthenticatedRootBudgets.Certificate` for the same source environment and preparation. It supplies the original local, auxiliary, base and permitted decapsulation query bounds. Its unrelated original Post field is not installed into the new protocol execution: the existing checked challenge-certificate constructor replaces only that field and its budget with the literal selected wrapper in each world.

Write `a = max(c.qLocal, 64) + c.qDecap`, `s = 34 + c.qBase + c.qDecap`, and `C = 1 + a + a + 32 + s + c.qAux`. These are the existing concrete callback and selector costs. `BeforeResources.client_uniform` uses the actual preparation/application callbacks, initializer, selector and auxiliary implementation to charge the entire saved callback and outside continuation at `1 + 2C + qPost·16C`. The two publication callbacks are both paid even when serialization returns no frame. The monitor erases to the original complete query tree, so refused and stopped executions are charged through the point where they stop.

`compiled_uniform` adds the complete prelude's uniform allowance to that suffix allowance with `qPost = 1 + q`. Proof attachment contributes no query. `prefix_class` transfers every original prefix hash/uniform class bound through exact erasure of the stored private packet, captured callback and carried selection. This retains all completed and cached outcomes and the original draw order.

## Original-interface prefix bill

The remaining premise names are the original source-interface allowances, not abstract costs of the finished reduction. `qKeygen` pays the actual interpreted KEM key generator; `qPre`, `qOne` and `qPhase1Write` pay the prekey generator, one-time generator and Phase-1 writer; `qMain` bounds the complete original scheduler for every publication reply. `qSelector` bounds every interpreted selector request, and `qLocal` bounds each safe original native callback from every actual local state. `qEphemeral` and `qEncaps` pay the interpreted ephemeral generator and each possible native or total encapsulation. `qPeer`, `qPlaintext` and `qWriter` pay the actual auxiliary reserve-peer, reserve-plaintext and response-writer callbacks. These quantified query bounds are retained explicitly. The similarly named parameter `qLocal` is an interpreted callback allowance, whereas `c.qLocal` is the certificate's original local-interface allowance.

With these names, define `U = qKeygen + 32 + qPre + qOne + qPhase1Write + (qMain + q)·(1 + qSelector + 69qLocal) + qEphemeral + 2qEncaps + qPeer + qPlaintext + qWriter`. The two encapsulations are both present in this source-preparation bill. Define `H = (69qMain + 1 + 69q) + (7 + 67q)` and `V = U + 184 + (7 + 67q)·(76 + a + a + 32 + s + c.qAux)`. The 184 sampled bytes are the source-ordered 64-byte initial output, 76-byte parent expansion, 12-byte nonce and 32-byte next-chain draw; they are not independent resamplings of repeated projections.

`SourceBills.prefix_bills` derives `H` and `V` for each bit's actual generated prefix by instantiating the existing full source preparation and cached-parent continuation theorem. The exact original `post` is the challenge wrapper and is bounded by `q`, derived from the same all-reply adversary certificate. The callback certificate's non-Post fields remain unchanged.

`SourceBills.source_bills` establishes four classes for that same complete guard-free oracle program: uniform requests at most `V + 1 + 2C + (1 + q)·16C`; routed public hash requests at most `H + 2 + q`; attempted selected seals at most `2 + q`; and adaptive raw openings at most `2 + q`. Both source bit wrappers and every permitted source reply are covered. These are query bounds, not a claim about wall-clock cost or fixed-size attacker input; the ordinary computational interface still requires the usual efficient programs and bounded input lengths. Deterministic native primitive implementations remain trusted.

## Privacy consumer and scope

`SourceBills.pair` instantiates the existing checked before privacy inequality with `qH = H + 2 + q` and `qR = qS = 2 + q`, requiring `qS < 2^96`. It names both complete source reductions through `CertifiedPrivacy.source` and `loss`. Each world's loss contains its validation IND$ advantage, `qH/2^128`, twice the sum of its `qR` indexed modified nonce-AEAD INT-CTXT advantages, `qR/2^512`, and its view IND$ advantage. The full uniform ledger is established for the same programs by `source_bills`; no ambient callback work is called free.

This closes the explicit source-interface query accounting for the before component comparison. It does not yet join that comparison to the unfiltered source secrecy event, account for the initial Builder and complementary phases, discharge the target-parent alias term, or bound the sticky nonce-refusal mass. Global session/identity/record selection and global application-interface composition remain outside these six statements. No new primitive game or cryptographic assumption, source edit, snapshot or persistence condition is added.
