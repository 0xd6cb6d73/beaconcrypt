# Native record replies and persistent entry facts

`PqxdhRecordFactsOriginNative` proves twelve guarded statements connecting the actual flattened native interface to record witnesses. `native_serverRaw_run` and `native_beaconRaw_run` identify the exact source dispatcher selected by raw delivery and preserve the environment state. The four native send and receive witness theorems then retain the actual requested or routed handle, literal optional reply, and complete private poststate. Successful receives preserve the actual plaintext in the hidden-key dictionary witness; successful returned sends use only the existing codec `FrameReadBack` contract.

`EntryFacts` states the two structural properties of one literal transcript entry: each successful published ciphertext has its sending-handle witness, and each successful raw receive has an actual receiving handle and accepted-record witness. `native_entryFacts_before` derives these facts from every native query. Non-record queries and failed sends cannot create either successful record observation. `native_entryFacts` transports those witnesses to the complete resulting control state using the independently established source control transition and caller-known-kernel preservation. `native_send_published` handles the source send helper used by experiment-generated test and fresh-message commands; its message remains the message actually passed to that helper.

The helper theorems `accepted_mono`, `published_mono`, and `entryFacts_mono` retain exact record evidence under source control progress and seal-dictionary growth. They keep the distinction between caller-known kernels and hidden coordinate witnesses. The source supplies those progress and growth facts separately; these internal preservation lemmas do not assert the final security event as an assumption.

Hidden-coordinate execution uses replay or random mode, with the starting control safety explicit. No selected-key honesty premise is imposed. All native queries, full private state, source order and instrumentation remain unchanged; no new cost bound or free-work claim is introduced. This module supplies facts for one native reply and their preservation. It does not yet establish the complete secrecy-ledger transcript invariant or the unpublished-record probability bound, and it adds no primitive, deployment, persistence or snapshot assumption.
