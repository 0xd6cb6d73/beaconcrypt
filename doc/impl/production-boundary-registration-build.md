The existing `PqxdhServerRegistrationPublication.source_build_exact` supplies the separately maintained deterministic callback/source execution equation; its StateM scope is not silently promoted to a probabilistic claim here.

`native_seal_exact` expands the original native seal callback to its actual AEAD, shared-cache hash and optional inner frame writer program. `seal_complete` preserves that entire evaluated program before the original successful-result log update. The existing interpreter appends a seal context only if this inner callback returns `some`. Thus an inner writer failure retains the actual preceding primitive and cache effects but adds no new `ghost.seals` entry. This corrects the earlier survey wording that treated every failed inner writer as logged; the source and frozen interface are unchanged.

The query accounting is preserved at the same tail and native interfaces. Initializer work, base callbacks, allocations, erasure, writer calls and arbitrary continuation work are not declared free. No independent query cap, root reduction, new sampling distribution or collision term is asserted by this module.
