# Private honest application requests in the live experiment

`LiveApplicationObservation` adds a private honest application interface to the existing replicated Server and Beacon source services. A public honest request names an actual owner route and an application request value. The application callback returns an optional payload using only the application state and its explicit base-oracle interface; the wrapper does not pass the current role state or shared CTX cache to that callback. A payload is then handed to the selected actual source send. If the callback declines, no source send occurs. The wrapper preserves the callback state even when the source send fails.

The application request type describes the application's public control input. It does not automatically make the returned payload secret: an application can return a publicly known value, its initial state can be correlated with other state, and its callback parameters can retain prior information. This interface supplies a place for an actual private honest message sampler in the common experiment. Its distribution and any target confidentiality result still require the enclosing source experiment and cryptographic reductions.

The public service retains every original source operation, including chosen-plaintext sends, arbitrary raw receive attempts returning the actual optional plaintext, real public fixed-HKDF queries, public commitment queries, caller randomness, and current-chain or skipped-material compromise replies. Additional `deliverServer` and `deliverBeacon` operations expose acceptance alone. These are two distinct observation capabilities. In particular, a raw API response that decrypts a target message reveals that plaintext: a confidentiality consumer must exclude or otherwise account for that disclosure through its checked target/freshness rule. This module does not silently replace the privileged reply with a bit.

A public log records each public request and its actual reply, including failure. An honest-send entry contains its owner and application request, followed by its actual optional ciphertext; the privately supplied plaintext is not added as an event argument. Original chosen-plaintext source requests still contain the caller's plaintext, and original privileged receive replies still contain their returned plaintext. The public result discards the final role, application and primitive states, preserving only the client result and public log.

| Checked statements | Meaning |
| --- | --- |
| `lower_query`, `lower_client` | Compiling public requests into the original source and private application interfaces preserves the complete monadic execution through every adaptive continuation. An honest request invokes the application first and the source send only if a payload exists. |
| `application_run`, `source_run`, `honest_send_complete` | Every operation preserves all unrelated state. The application wrapper retains the complete protocol and shared primitive state, while the source wrapper retains the complete application state. Honest sends preserve this order and all optional outcomes. |
| `source_query_bounds`, `application_query_bounds`, `honest_send_bound` | Packaging state does not change any underlying oracle-call count. An honest send pays the entire application callback bill plus its possible source-send bill. |
| `logged_query`, `logged_query_erasure`, `logged_client_erasure` | Logging happens after each operation's real effects. Erasing the log recovers the same result and complete private state, even under arbitrary adaptive scheduling. |
| `public_observation_compiler`, `public_observation_bound` | The direct service and compiled interface have the same complete public-observation program. Logging and final private-state erasure preserve its underlying oracle bill exactly. |
| `lower_source_step`, `lower_source_budget` | Each public request makes at most one original source call, so a schedule bounded by `qPublic` has at most `qPublic` source calls. Rejected raw, reveal and send attempts remain counted. |
| `lower_application_step`, `lower_application_budget` | Only honest application requests invoke the private callback. A selective cap `qHonest` remains valid through every possible source, raw-delivery and reveal continuation. |
| `public_query_bound`, `public_schedule_bound` | If each actual source callback costs at most `qSource` and each application callback at most `qApplication` for a selected oracle predicate, the full schedule costs at most `qPublic*qSource + qHonest*qApplication`. These are callback work bounds, not security premises. |

`LiveApplicationNative` instantiates this service with `RawCtxProtocolReveals.sourceImpl`, including both indexed role families, actual peer lookup and selected associated data, the real fixed-HKDF callback, the one shared CTX primitive cache, and live compromise histories. `native_query` identifies the direct and compiled full-state services exactly. `native_observation` evaluates them after the same arbitrary joint initial sampler and proves equality of the complete distribution of public initial context, final adaptive result and chronological public log. It imposes no independence between initial owners, application state and the primitive state.

The native resource statements account for the actual source and application work. `source_uniform` derives a conservative cap of 64 uniform-oracle calls per original source operation from the existing native source ledger; this covers one possible 64-byte commitment-cache miss. `observation_uniform` gives `64*qPublic + qHonest*qApplication`, including logging, failed operations, public queries and reveals. `initial_uniform` adds the full original sampler allowance `qInitial`. Uniform calls count actual oracle invocations: a commitment miss requires 64 byte-valued calls. Deterministic fixed HKDF, AEAD, frame parsing, byte copying, lookup, logging and local callback computation retain their source operations and actual work; zero extra uniform randomness does not make that work free. The original source/native resource ledgers remain the place to derive tighter operation-specific bounds.

These 24 guarded statements establish an operational private-application and public-observation interface. They do not prove message secrecy, record authentication, a ProVerif trace simulation, arbitrary registration/session creation, or a generated-session assignment map. They introduce no primitive security assumption, no key-independence assertion and no snapshot or persistence operation. The common experiment must still instantiate the honest message distribution, create and register sessions, connect the live observations to the symbolic events, impose the actual reveal/freshness rules, and apply the existing component reductions at their checked source interfaces.
