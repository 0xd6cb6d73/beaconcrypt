# Complete local source execution with a growing private table

`PqxdhRecordLiftChainCompiler` executes the actual labeled receive and send control flow with a private full76 table and an arbitrary complete primitive state. Receive follows the extracted source rank; it has no fuel fallback or selected trace. Each KDF callback returns the successor coordinate and the same-output material label to the existing source continuation. Opening receives the complete pending state interpreted at the current table, and its actual optional plaintext is returned through the source finish operation. Send advances the source kernel before calling the actual seal/writer continuation, retaining that advanced kernel even on failure.

`receive_erasure` and `send_erasure` identify the complete evaluated result with the ordinary source programs. The erased result uses the final table, which may have grown during several skipped-key derivations. Every native primitive-state field and optional reply is retained. The proof therefore covers instrumentation, shared hash cache and any additional native bookkeeping supplied as that state. It drops only the private table and coordinate annotations. It uses the actual source callback equalities from `PqxdhRecordLiftRealTable` at each supported reply; a fixed function on the initial kernel would not establish this result.

The generic theorem has two explicit operational implementation obligations. `LookupPreserves` requires supported lookup results to extend earlier entries, store the returned full76 reply and preserve the supplied table invariant. `LookupRealized` requires the evaluated lookup distribution, after dropping only its private table, to equal the native KDF call at the exact currently interpreted input and ratchet label. Neither is a security assumption. `realLookup` executes the native KDF callback on every invocation, including repeated coordinates, then stores its returned bytes. `realLookup_realized` holds for every such native callback. `realLookup_preserves` derives the support obligations from ordinary functional KDF correctness and the previously proved real table invariant. That invariant starts empty, permits byte aliases, and is preserved by actual recording.

`real_receive_erasure` and `real_send_erasure` discharge these lookup obligations internally. Their remaining `KdfReal` parameter states only that the native call returns the existing fixed source's full76 response; it says nothing about secret distributions or winning events. The concrete `PqxdhRecordLiftWorldCompiler.primitives_kdf`, `nativeKdf_real`, and `callback_world` joins supply this fact for the actual World handler with exactly one native KDF counter increment, unchanged ROM cache, unchanged uniform count, and unchanged other counters. Those downstream joins must be reviewed and integrated together with the dynamic world compiler; this local module does not assume that global composition is already proved.

`receive_preserves`, `admitted_receive_preserves`, and `send_preserves` prove that all earlier table entries survive, the table invariant remains valid, and the complete returned kernel keeps both live chains available and all skipped material labels present. Cached consumption, future publication and rollback use the original extracted array operations. `receive_source_support` shows that the local execution reaches only results of the original source oracle program. Consequently `receive_control` reuses the existing source control theorem: a rejected receive returns its entire entry kernel; acceptance consumes its target and preserves all previous consumption. This does not assume that opening returns an honest plaintext.

The admitted forms start from actual source `normalBegin` operations, with their full rejection and cached/future behavior. The preservation theorem states the existing control-capacity requirement needed for admitted publication, and every chain/cache availability premise is explicit. The generic helpers permit arbitrary opening/sealing effects, so they make no claim that those effects are free. Exact native-state equality transports concrete instrumentation; the existing source budgets remain at most 51 KDF callbacks and one opening for a receive, and one KDF plus one sealing/writer path for a send. Global interface caps must still be supplied by the checked World budget and its source compiler.

These are local operational equalities and invariants. They do not prove a dynamic map/list/world simulation, slot provenance after an arbitrary global schedule, coordinate-counter alignment for every resulting kernel, target-input independence, the real-to-uniform evolving-chain hybrid, alias probabilities, or a CTX security lift. Subsequent source-coordinate and global-world joins must prove those additional statements while retaining the same complete state and real public KDF services. Compiler and primitive implementation correctness remain outside these proofs. Durable storage, snapshots and restoration are outside the experiment.
