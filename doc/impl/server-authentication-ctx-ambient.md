# Shared source work in the selected CTX compiler

`PqxdhServerAuthCtxAmbient` supplies the ordinary work surrounding the selected sealing and raw-opening callbacks. It forwards every original uniform query and every public or locally known commitment query into the same dynamic CTX interface. Its executable definitions require no selected-key argument. Arbitrary supplied known material can still have equal bytes, and this operational fact establishes neither independence nor nonexposure.

`coin_full` and `coin_program` preserve the entire selected-key, known-key and shared-cache component state while returning the original samples of the complete adaptive source computation. `coin_source` gives the corresponding original auxiliary/cache projection. The continuation is not conditioned on later acceptance, and rejected source work keeps its uniform queries.

`hash_source` identifies the forwarded hash with the actual original commitment random oracle on the same input bytes and cache. The cache remains inside the component interpreter; it is not supplied to the executable as a fabricated prior transcript. `native_source` and `native_program` apply this equation to the complete known-material native interface. Fixed HKDF, AEAD seal/open and optional frame writing are evaluated as the original functional source operations. Only the actual hash request is forwarded. Optional failure and every adaptive continuation retain their exact replies and projected auxiliary/cache poststate.

`coin_bound` preserves the source computation's total uniform-query allowance. `coin_other` proves that this forwarding issues no hash, selected seal or selected raw calls. `native_hash` preserves the original count of attempted native hash requests, including requests whose enclosing record operation later rejects. `native_other` proves that this known-material work contributes no selected seal, selected raw or explicit uniform requests. Local fixed-HKDF, AEAD, codec and list/cache work remains computation; these statements are oracle counts, not a runtime bound. Randomness used internally by the commitment random-oracle interpreter remains covered by its existing resource accounting.

These ten statements add no primitive or protocol security assumption. They are callback and full-program source equalities and query bounds. The actual logged Server tail, Beacon tail, adaptive authentication scheduler, one-use target accounting, selected-key distribution and ordinary forgery-event consumer remain separate required composition steps. In particular, this module does not claim that an arbitrary private-state predicate is an executable primitive distinguisher.
