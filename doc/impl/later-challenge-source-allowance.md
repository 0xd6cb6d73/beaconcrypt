# Source-derived continuation allowance

This result removes the semantic `Fits` test from the complete before-phase source comparison. The reduction now takes the existing adversary resource certificate, executes the actual generated source prelude, attaches a proof to its own returned callback, and executes that complete callback without testing its resource predicate. The new program equals the previous guarded program as an oracle query tree; the equality includes both original bit wrappers, every possible oracle reply, all source draws, and the complete saved continuation. This closes a resource-interface gap in the before comparison, not the entire evolving-chain secrecy theorem.

## Derivation from the original interface

Let `b` be the existing `PqxdhRecordConfidentialityChallenge.AdvBounded` per-kind budget and let `q = ∑ kind, b kind`. This assumption bounds the adversary's ordinary source requests for every generated selection and every Builder reply. Its kinds include owner send/receive services, public computations, reveals, source operations, uniform/base/decapsulation work and finish requests. A challenge request counts as its literal send in the selected direction. It is an ordinary all-reply resource condition, not an authentication, freshness, secrecy or support assumption.

`CapturedFits.wrapped_total` and `handler_total` show that either bit wrapper makes at most the original `q` requests and a single wrapper request makes at most one Post request. `append_fits` retains the original quiet-inner certificate and adds the entire outside continuation's allowance. `captured_fits` then inducts over the actual adversary query tree: any source-generated saved callback together with either complete resumed wrapper satisfies `Fits (1 + q)`. The loose cap keeps the original global allowance for every remaining subtree. No marginal distribution argument, assumed honest selection, successful target, or conditional probability is used.

`builder_fits` and `shared_fits` carry this statement through the actual initial Builder and shared callback scanner. A Builder cut with absent wrapper metadata is explicitly outside the predicate's claim. `PreparedFits.prefix_fits` and `run_fits` instantiate the real source callbacks and use the original collector's exact missing-address result; completed and cached branches cannot manufacture a pending descriptor. `SamplerFits` carries the same certificate through preparation, the actual selected continuation and all correlated 64/76/12/32-byte material draws. Those draws and their order are unchanged.

`GeneratedFits.run_fits` preserves the full generated carrier and selection. `adversary_total` derives `q` by summing the existing complete finite query partition. `certified` attaches the proof from the actual oracle program's syntactic support; `certified_erase` proves that erasing the proof returns the literal original program. Proof attachment does not reject, resample or condition any outcome.

## Complete reduction and explicit losses

`BeforeUnguarded.key_fits` derives the before-client certificate from its generated carrier. `client` has no branch on `Fits`; it retains the original address-alias exclusion, source callback, retained parent material, monitor, optional refusal, and final decision. `client_eq` is exact equality with the old client on a certified input. `compiled` forwards the entire original generated prelude and executes this client. `compiled_eq` proves equality with the existing full-state compiled query tree for any pair of prefix and continuation bits. It has no access to the challenger's private state and resets no interpreter history.

`CertifiedPrivacy.pair` applies the already checked full-history random-middle equality and adaptive CTX reductions to the two complete guard-free programs `C₀` and `C₁`. In both directions it proves `Pr[source(C₀)=true] ≤ Pr[source(C₁)=true] + L₀ + L₁`, exchanging the two source probabilities for the reverse direction. For `qR = qS = 2 + q` and `qH = qHashPre + 2 + q`, each `Lb` is the existing `privacyLoss` instantiated with the actual complete program `Cb`: its validation IND$ advantage, `qH / 2^128`, twice the sum of its `qR` indexed modified nonce-AEAD INT-CTXT advantages, `qR / 2^512`, and its view IND$ advantage. The theorem requires `qS < 2^96`. It does not add a primitive assumption or replace the ordinary endpoints by a protocol conclusion.

`CertifiedPrivacy.bills` establishes those selected-seal, raw-opening and routed-hash caps from explicit actual prelude hash and uniform bounds. Both complete continuation wrappers use `1 + q`; the saved operation adds the other one. Public prefix hashes remain real and billed. The theorem's `qUniformPre` is a prefix bound, not a claim about total uniform or native work. Existing source callback/base/decapsulation certificates and the remaining complete suffix uniform accounting must be joined separately; ambient work is not declared free.

## Scope still open

The result is the before observation's complete ordinary component comparison. Its original address-alias branch and source phase/monitor filtering are still present. Connecting it to the unfiltered source secrecy event requires the original freshness/reveal decision, explicit sticky nonce-refusal and alias charges, initial Builder and other phase contributions, and the global native/uniform resource and target-selection accounting. Initial Builder cuts with absent request metadata are not eliminated by this result. No snapshot or persistence model is introduced. Every primitive remains a trusted implementation of its stated game interface.
