# Literal writer outcomes for newly generated hidden records

`PqxdhRecordFactsOriginPublicationStep` proves four source support facts needed to distinguish publication before a receive from a hidden record whose writer failed. For every seal entry present after the operation, the proof preserves two alternatives: the entry already existed before the operation, or the operation created it and the exact source writer either rejected its matching frame or returned ciphertext bytes decoding to that frame. `WriterOutcome` records these literal alternatives. It does not treat a produced frame as a successfully published ciphertext.

`sealing_entry` derives this classification from the actual hidden sealing service, including unchanged dictionaries, every other coordinate, associated-data width refusal and the exact writer result. `kernelSend_entry` follows the actual source order through send admission, lookup and sealing; the selected coordinate is the kernel's current sending coordinate. Exhaustion retains only the prior entries. `ownerSend_entry` supplies the physical sender's installed slot and direction from the source control invariant and actual handle lookup. Empty plaintext and caller-known sends retain the hidden dictionary's previous entries. `ownerRun_entry` preserves the classification through the actual tagged publication callback and its full poststate.

The statements require replay/random hidden modes and the existing successful-writer `FrameReadBack` contract. The owner-level local facts additionally take actual control safety and handle lookup as induction inputs. No selected-key honesty, temporal publication invariant, plaintext substitution or security event is assumed. These support facts execute the unchanged interpreter, retaining its private state, source caches, counters, logs, optional replies and writer failure branches. They add no primitive contract, query call, probability bound or free-work claim.

The complete adaptive prefix invariant and unpublished-before-acceptance probability bound remain separate work. In particular, these local statements alone do not identify which earlier transcript prefix contains a ciphertext, nor show that an accepted dictionary entry was available before its receive. Four exact guarded axiom checks allow only the standard `propext`, `Classical.choice` and `Quot.sound` axioms. No Rust, registration, persistence or snapshot behavior changes.
