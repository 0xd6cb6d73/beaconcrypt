`PqxdhInitialChainComposition` connects the actual single 64-byte initialization call to both complete finite directional derivation histories. It starts with an independently uniform 32-byte root and preserves the entire context and observer. One initial Extract/HMAC replacement precedes the previously checked ordered left- and right-direction hops. Every substituted expansion keeps its message key, nonce and next-chain correlations; the source's two initial chains are the two halves of the same 64-byte prefix.

This is the next component after the published ordered-chain result `fdee29a2e0c6800e470656cb9d520917f27ca053`. It does not assert that a native protocol root already has this independent distribution. ## Source call and complete distributions

`sourceInitialChains` invokes `source.crypto.hkdf root INFO_R 64` once and creates two typed 32-byte halves. `sourceInitialChains_bytes` identifies those halves with the existing source byte-model `rootChains`. `initialized_pair_source` and `sourceInitialChains_eq` use the already stated functional prefix-consistency contract to identify the same halves with the first and second projections of one complete 76-byte source expansion. They do not sample the projections independently or assume constructor injectivity. The production orientation remains the established first-half Server-to-Beacon and second-half Beacon-to-Server mapping; complementary endpoint initialization has its existing conditional extracted-kernel refinement.

`actualInitializedGame` executes that 64-byte source operation, then builds both real finite directional histories and invokes the complete observer. `actualInitializedGame_eq` is equality of the whole oracle computation with the shared-76-byte proof representation. The representation's unused nonce projection is never supplied as an independent initialization value. Functional output equality is not asserted to preserve internal primitive-query traces: the full-output reduction conservatively computes both HMAC blocks even though initialization observes only the first block.

`initial_chains_observed` proves equality of evaluated distributions for every continuation on both halves, using the already checked full-output splitting law and losslessness only for the discarded independent samples. `rootSampler` samples context first, then all 32 root bytes, returning the context and exact source input. `initialObserver` constructs both complete source suffixes from the same substituted output. `independent_initial_eq_bidirectional` proves that the initial independent-output game is exactly the existing bidirectional experiment before any directional replacement. The equalities retain the full continuation and joint state; equality of marginal chain distributions is not used as a replacement for that obligation.

## Reductions and loss order

`initialLoss` names two concrete existing reductions for the exact root sampler and both-direction observer: `fullExtractReduction` in the fixed-zero-salt whole-PRK Extract game and `fullExpandReduction` in the uniform-secret-key HMAC PRF game. `initialized_bound` proves the initial hop under the existing `SourceFullCorrect` functional contract. `initialized_evolving_bound` combines it with the checked bidirectional ordered sums; `actualInitializedGame_evolving_bound` transfers that bound to the actual 64-byte source call.

For fixed derivation counts L and R, the bound has one initialization Extract/HMAC pair, then L left-direction pairs and R right-direction pairs. Each pair is the exact named ordinary component advantage, with coefficient one. Each HMAC reduction makes two adaptive challenge calls; no new primitive endpoint, statistical guessing term or session-selection factor is inserted. Public deterministic HKDF evaluations remain real inside every observer and remaining source suffix. The source contract uses the existing ratchet label; the separate PQXDH root domain and its reductions remain unchanged.

The left hops retain a fully real right direction inside their observer. The right hops retain the fully replaced left history inside their context sampler. Consequently both histories, both final live chains, shared context and the entire final observation remain in the same experiment when the ordered hybrid sum is applied. This is a fixed-history composition, not a re-proof of the symbolic state machine or a claim of adaptive snapshot/reveal security.

## Remaining protocol and trust boundary

The independent root is the explicitly defined entry distribution of this component. Connecting it to actual authenticated PQXDH requires the existing root reductions and their exact source continuation, rather than replacing that obligation by a security assumption. Likewise, proving freshness under copied state, skipped keys, persistence rollback, current-chain compromise and arbitrary raw traffic still requires the common experiment. The previously checked source fact that current-chain knowledge determines all descendants remains in force; no post-compromise recovery is implied.

The perfect HKDF/HMAC functional and security contracts remain exactly those of the retained full-output component. Extract exposes the whole PRK and exact sampler context; a later protocol instantiation must establish its actual distribution and permissible observations. No public fixed-HKDF/random-table advantage, old `qRoot / 2^256` interpretation or independent replacement of repeated projections is used. Native primitive implementations, compiler behavior, allocator/OS behavior, physical erasure, foreign copies and trusted storage remain external. Persistence integrity, rollback resistance, linearizable CAS, crash behavior and ownership remain deployment premises.
