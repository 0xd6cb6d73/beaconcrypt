# Collisions in the actual lazy cache

`PqxdhRecordFactsCollisionCache` proves eleven statements connecting concrete cache equalities to the checked chronological collision experiment. The conclusion concerns the original memoizing oracle; repeated queries still return the stored value. It is a statistical component for the record lift, not a new security contract or a completed BindingStatement.

The `Recorded` invariant says that every cached answer appears in the draw history for its input class. The `Separated` invariant says that equal cached values at distinct inputs imply the collision flag whenever at least one input is a target. `pool_mono`, `bad_mono`, `recorded_insert`, `hit_bad` and `separated_insert` prove their exact insertion rules. A new target is compared with both prior lists, while a new ordinary value is compared only with prior targets. This handles either temporal ordering of a target and matching public hash without charging ordinary-to-ordinary collisions.

`initial_good`, `query_good`, and `program_good` derive and preserve the conjunction of those invariants from the literal empty state through every supported adaptive run. Cache hits preserve the same answer and add no draw; finite coin queries preserve both caches and collision history. These are proved invariants, not assumptions that a protocol event already has an honest origin.

`collision_detected` supplies the support-wise event inclusion. `cache_collision_bound` combines that inclusion, the exact compiler projection, and transported source request caps to bound the concrete cache event in the original plain oracle. `ctx_cache_collision_bound` specializes its range to the actual 64-byte CTX digest, yielding S(S+H)/2^512 for S target requests and H ordinary requests. Requests, cache misses and digest draws remain distinct: request caps upper-bound the draws and repeated cached queries cannot increase the bound.

The module has no primitive, codec, key-injectivity or freshness premise. The finite oracle and its sampler are the explicitly defined ideal statistical experiment. All eleven statements have exact guarded axiom checks permitting only propext, Classical.choice and Quot.sound. The global protocol must still supply the input encoding, exact source compiler, source and reduction counts, and accepted-record binding event inclusion. The original source uniform/query bill remains separate, including work omitted only through the independently checked observation law. No actual raw verification attempt or ambient work is declared free.
