# Unconditional guessing of the first selected random tag

`PqxdhServerAuthPublicationTag` supplies the statistical calculation for the exact ordinary random first-seal law. Its three statements do not condition on writer failure, successful publication or any attacker-selected event.

`fixed_guess` bounds a fixed optional candidate's equality to a uniform 16-byte tag by the inverse cardinality of that tag space. An absent candidate cannot win. `independent_guess` allows the candidate to come from any complete probabilistic continuation which is not given the tag. It applies the checked distribution-level interchange to that entire continuation, then the same point-mass bound. The continuation can adapt to its own coin and public-oracle replies; its runtime is not treated as zero.

`first_seal_guess` consumes `PublicationPrivateView.first_seal_suffix`. It compares a candidate chosen from the actual final public result with the tag of the actual optional selected CTX record. The source's body, tag and commitment draws all remain in the experiment. The resulting bound is exactly `2^-128`, using the existing 16-byte cardinality theorem. The source suffix retains all public cache effects; every tag-bearing private record copy is handled by the preceding complete projection proof. No additional query, target-selection factor or primitive-security premise is introduced by this probability calculation.

The operational preconditions remain explicit: the selected nonce/suffix tables are unused at this first seal, and the fixed suffix has zero selected seal/raw requests and is not supplied the returned selected record. The literal initial state and quiet-prefix facts already prove the first condition at that component boundary. The concrete mixed-codec forced-frame client must still discharge the suffix shape, preserve its complete source budgets under changed replies, and associate this record with the actual unpublished builder occurrence. The ordinary privacy reduction and original source/key-schedule event transports remain separate consumers. This theorem does not assert a uniform tag distribution after conditioning on an arbitrary writer's failure.
