# Same-execution received-entry marker

`PqxdhRecordFactsOriginMarkerEntry.EntryFact` connects each literal successful received transcript entry to its physical handle and the selected analysis flag. It records that the handle is already installed, either caller-known or hidden. If its current hidden slot, opposite physical direction, and actual returned sequence identify the selected record, the flag must be true in that same execution.

`entry_mono` transports this fact through actual forward control evolution and sticky flag persistence. The installed-handle classification justifies pulling the current hidden slot back to the earlier receive; caller-known persistence excludes a known-to-hidden shortcut. `native_before` obtains the fact from the exact raw command and its literal optional plaintext. `native_final` moves it to the command's complete final state. `secrecy_entry` handles experiment-generated send entries, which contain no receive event.

These four structural statements require no new primitive assumption or ideal-mode restriction. They are the induction predicate and exact command cases for the complete marked ledger theorem; they do not alone claim the final unpublished-origin probability.
