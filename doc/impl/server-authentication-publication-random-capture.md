# Actual reference capture and unconditional random-tag bound

`PqxdhServerAuthPublicationBlindKnown`, `PqxdhServerAuthPublicationGuess`, and `PqxdhServerAuthPublicationRandom` prove the random-game endpoint for the actual publication reference. Its complete context sampler, residual76 sampler, adaptive source callbacks, optional stopping, known-key operations, and original replies all remain in the experiment. The private observer captures the actual selected record and stops at the first selected raw request before forwarding that request, decoding it in the component, looking up a key, or opening a ciphertext. Malformed raw requests are stopped too. Its final Boolean tests whether the supplied decoder extracts the captured record's 16-byte tag from those exact requested bytes.

The complete reference has the previously checked syntactic replacement equality: it executes each actual selected sealing query, but replacing a successful reply by a fixed record does not change the full component program. The new known-key consumer transports this equality through the actual dynamic known-key compiler, retaining all known-key histories and public hash effects. It requires no selected-key argument and does not exclude equal known-key bytes or arbitrary correlations. Known-key work stays real and is charged through the same shared interface.

The adaptive capture proof derives its first-seal conditions from the actual source program and initially empty component state. Before the first selected seal, only ordinary uniform or public hash queries can continue; they preserve the selected private table and unused nonce state. A raw request before that seal cannot win. The actual all-reply cap of one selected seal implies every later continuation has zero selected seals. The cutoff also has zero selected raw calls. Therefore the previously checked private-view erasure applies to the whole remaining computation, including all tag-bearing private copies. The actual optional sealing reply is retained by the observer; an actual `None` contributes no winning candidate. No probability is conditioned on writer failure, sealing success, or reaching the first seal.

`PublicationRandom.random_bound` concludes that the existing ordinary `randomView` of this exact reference decision succeeds with probability at most `2^-128`. The source continuation receives only the fixed replacement, whereas the observer's private state retains the actual challenger record. The proof keeps every body, tag, and commitment draw and uses the complete-continuation interchange from the earlier tag lemma. This is an unconditional point-mass bound for this constructed experiment, not a claim that a tag remains uniform after conditioning on an arbitrary writer's result.

`decision_bills` supplies separate ordinary uniform and shared-hash allowances `H = entryReductionBudget caps qCoin Q qHash qH + 76`, one selected seal, and zero selected raw calls. It consumes the complete mixed-reference resource proofs from commit `411b9499ba65b01945e2bc4208ffc5ff26e4ace5`, with the same concrete KEM callback bounds and original four adversary budgets. `decision_plaintext` derives the total selected plaintext bound `Usize.max` from the actual checked `8 + payload.length` gate. These are all-reply oracle certificates, not runtime bounds or a bound on known-key local encryption work. Generalized cutoff preservation retains weighted byte budgets directly.

The actual unpublished source event still needs its separate same-run failure/reference coupling and receipt association. This package does not equate failed publication with the reference execution, nor does it conclude that every accepted record was published. The ordinary real/random IND$ comparison, its explicit primitive ledgers, and the new accepted-observation source/key-schedule transport must still be joined before obtaining a production-order publication bound. The earlier B authentication event and all maintained ProVerif queries are unchanged. No codec totality, encoding injectivity, session uniqueness from equal bytes, or new cryptographic assumption is introduced.
