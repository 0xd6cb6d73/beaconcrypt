Rejection after decapsulation and before root processing retains the actual decapsulation observation. This is an operational composition theorem; it is not yet a full protocol secrecy reduction.

The complete owner still uses the existing challenge-marker dispatch. An exact selected challenge ciphertext produces an opaque marker.
