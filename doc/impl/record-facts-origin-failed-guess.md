# Unconditional guessing after a failed selected writer

`PqxdhRecordFactsOriginFailedGuess` proves five guarded distribution and probability statements for the selected failed-writer continuation. The experiment samples the original full uniform 512-bit commitment before inspecting the literal writer result. It continues only when that result is absent; a successful writer stops this selected unpublished target and returns no selected continuation result. Thus no successful ciphertext is returned while pretending it reveals only a bit.

The continuation runs the actual muted source-service interpreter from the exact `OriginSelectedSeal.hiddenResult` poststate. It returns the complete source continuation result and the full state under the checked private-copy projection. `continuation_fixed` proves that this evaluated distribution is the same for every digest when the fixed continuation makes no later selected seal. This follows from the actual state wiring and combined key/log projection, without assuming that writer success is independent of the digest.

`experiment_form` rewrites the whole stopped experiment as a digest-dependent choice between two fixed continuations: stop, or run the absent-writer continuation at a fixed representative projected state. It is an unconditional distribution equality. The choice bit is the actual writer failure test; no conditional distribution given writer failure is claimed to be uniform.

`failed_guess_bound` applies the previously checked two-branch point-mass bound. A guess computed from the complete retained continuation output succeeds with probability at most `2 / 2^512`. `source_failed_guess_bound` uses the literal source continuation `next none` and discharges its no-later-selected-seal restriction from the existing attempted-coordinate freshness invariant, before any endpoint reply. Every original ambient/native operation remains in that continuation.

`failed_guesses_bound` takes a family indexed by `Fin attempts`, allowing each candidate to depend on the full adaptive continuation output. The same experiment's probability of any matching candidate is at most `2 * attempts / 2^512`; the finite union charges every candidate once. This theorem does not infer a production query cap from the index type. The consuming proof must identify the actual raw attempts, prove that their candidates fit this family, and supply the established receive count.

The body, tag, source input and preceding state are fixed before this commitment draw. `OriginSelectedSeal.source_sampler` supplies their exact source order for averaging over the actual pre-digest sampler. The remaining full-source work is that averaging, actual temporal seal selection, the erased-versus-muted first-match coupling, extraction of each raw candidate and the union over the source send cap. These local results do not yet establish the final `2 * R * S / 2^512` unpublished-origin statement. No new primitive or protocol assumption, writer restriction, conditioning premise or query-cost waiver is used.
