# Accept, HMAC and quiet-route resources

`PqxdhServerAuthCtxStateBounds` supplies fifteen concrete resource and state-footprint statements for the remaining routes of the original Server-authentication compiler. The actual acceptance, public HMAC, public commitment hash, uniform draw and installed-kernel reveal definitions are unchanged. The proofs cover arbitrary source and component replies, failed admission, table refusal and off-domain public calls. They use no accepted-state, honesty, freshness, non-aliasing or challenge-independence premise.

For acceptance, the total dynamic-call and explicit uniform-route bounds are `32 + E + 64`, where `E = caps.encapsUniform + caps.baseUniform * caps.encapsBase` is the existing complete direct/base encapsulation cost. These calls include the actual ephemeral scalar and a possible Extract-table miss. Selected seals, selected raw openings and forwarded CTX hashes are zero. Public HMAC has total and uniform-route bound sixty-four exactly on the original zero-salt, 192-byte domain, and zero outside that domain; its selected record and CTX-hash counts are zero. Outside-domain HMAC is still evaluated using the real primitive. These are upper bounds, so an existing table entry may require fewer calls.

`coin_support` proves that forwarding the actual uniform oracle preserves the entire syntactic output support across every adaptive continuation. `flat_support` applies that fact to the original flat source state and retains the actual designation flag. Neither theorem is a marginal key-distribution interchange. They permit the original supported source resource and mark facts to be used for arbitrary syntactically possible replies of the executable dynamic program.

`table_services_uniform` discharges the concrete lazy/designated derivation and public table costs. The unused builder and receive callbacks of this particular table-only service are literal pure computations; actual builders and receives are counted by their separate concrete modules. `accept_total` uses this service and the real source prefix, including all direct and base-interpreted KEM work. `hmac_total` retains the actual domain test and public table behavior. `accept_bills` and `hmac_bills` give the explicit uniform and zero other component classes for the same complete programs.

`accept_footprint` proves the actual allocation and pending-token `ResourceStep`, the original `MarkStep` that changes at most the current attempt's session mark, and preservation of the designation flag. It consumes the original source support and mark theorem rather than adding a callback simulation premise. `hmac_footprint` proves the corresponding unchanged allocation, Beacon, pending-token and mark fields through both real off-domain evaluation and on-domain table access. Its actual table and touch-log effects remain in the returned state.

`coin_bills` counts one actual adversary uniform request and zero hash or record requests. `hash_bills`, together with the existing concrete `CtxState.hash_bound`, counts the single public shared-hash request and zero selected seal, raw-opening or explicit uniform-route requests. The component interpreter's possible sixty-four digest samples remain separately counted by the existing source hash budget; zero explicit uniform routing does not make that hash free. `reveal_total` proves that the actual installed-kernel lookup has no component request. It does not change which source kernel can be revealed or assert a security property of that disclosure.

`coins_state`, `hash_state` and `reveal_state` prove that every supported reply retains the complete executable local state. This directly supplies the quiet routes' resource and mark footprints. The shared hash cache is still owned by the component interpreter, so unchanged local state does not claim that the private shared cache is unchanged. Every source field, table entry, transcript and installed kernel remains in the local state.

This package reuses exact reviewed `StopTrace` and `StopSource` dependencies from checkpoint `ba38eca4b3d8d130ce759c4733ff0a0629a5acc1`, including their guards and [stopped-control guide](server-authentication-stopped-control.md). No dependency proof or statement is modified. The new statements add no probability loss or selection factor. Full handler settlement, the stopped unused-endpoint invariant, global query accounting, actual challenge distribution and source-to-CTX authentication event remain consuming obligations.

The existing `KemBound` assumptions specify executable primitive-interface resource caps; primitive implementations are trusted. The original restricted server-authentication experiment, `revealSeed = false`, no-KCI scope, programmable Extract ROM and shared CTX/BLAKE2b ROM are unchanged. Local parsing, DH, HMAC/HKDF, KEM, primitive, writer and lookup work remains present; component-query counts do not assert constant runtime or erase local computation. Serialization implementation, saved-state restoration and persistence remain outside the approved scope.
