The complete `run_cover` theorem starts from the same literal source and component state as the original stopped compiler. ## The two actual finish paths

`observed_coin` and `observed_coins` preserve every original uniform draw and the entire observer/component state. Thus the actual probabilistic preparation prefix and root derivation return their original outcomes before the proof considers success or rejection. No sampling is conditioned on a successful finish.

`Ordinary` records a concrete source fact: the first Beacon input in the actual touch log is present in the ordinary private table. It is not a key-byte inequality or a computational security premise. `Covered` states that W1 or W2 implies either the ordinary observer has won or this occupied-input fact holds. The occupied branch is deliberately retained until the separate designation consumer establishes that the final winning entry uses the omitted selected input.

`derive_origins` preserves earlier seal receipts through the actual table derivation and Beacon touch. An ordinary derivation retains an existing selected-input label. At a newly designated read, the source latch supplies an absent previous label; the earlier origin relation then proves there cannot be a previous selected receipt. Nothing is inferred from equal root or message-key bytes.

`rejected_no_event` proves that an absent staged finish cannot create a first acceptance. `known_ordinary` retains the exact reached input and actual table occupancy through the complete ordinary post-root callback, including arbitrary native optional results and shared-cache effects.

`active_finish_cover` follows the literal finish program from its actual InitSent phase. It executes the full preparation and table computation. Rejected preparation or derivation cannot create acceptance. A returned ordinary root supplies a concrete occupied table entry; the first Beacon touch fixes that same input in the source history. A returned hidden label invokes the existing receipt proof with the actual challenger-produced optional plaintext, complete earlier seal history and actual source writer/log alternatives. The original final sequence-one, binding and publication gates determine whether acceptance occurs. In that selected branch, W1 or W2 therefore implies the ordinary observer's winning event.

`finish_cover` includes every other actual source phase. An inactive or already established Beacon makes no new attempt and preserves its previous coverage. The theorem does not invent a successful staged result or a plaintext for a rejected request.

`stopped_cover` retains coverage after the entire callback and its real checkpoint, including work before an outer refusal. `interpreted_cover` uses the actual reservation and joint source/observer invariant to establish the next alternative. `program_cover` propagates it through arbitrary reply-dependent continuations on normal terminal returns. `initial_cover` follows from literal empty acceptance instrumentation. `run_cover` then proves coverage for the original adversary's complete observed executable, with identity-seed disclosure disabled in this experiment. This helper leaves selected-input existence/equality explicit; the separate source-designation theorem obtains them from the actual winning entry and its complete source run.

The imported receipt proof applies it only to an actual accepted matching frame, ruling out the concrete failed-inner-writer alternative. It does not assume canonical wire bytes, full writer totality, assigned-ID equality across registrations, or properties of a native serialization implementation.

All statements preserve optional replies, prior receipts, every attempted opening and full source/component state. Known-key byte aliases remain allowed. No new security assumption, oracle request, advantage term or raw-attempt selection factor is added. The same ordinary all-attempt observer and complete compiler retain their previously checked attempted-query bounds; local KDF, native primitive, context sampling and other callback costs are not declared free.
